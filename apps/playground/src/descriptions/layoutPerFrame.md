# 프레임마다 다시 재는 레이아웃

{facet:layoutPerFrame}

`left` 처럼 자리를 바꾸는 CSS 값은 기하 속성이다. 브라우저는 그 값이 바뀐 장마다
스타일 → 레이아웃 → 페인트 → 합성을 전부 다시 돈다. 레이아웃 단계는 바뀐 값 하나만
고치는 것이 아니라 상자의 **자리와 크기를 둘 다** 다시 셈한다 — 이 조각에서 상자의
너비는 한 번도 바뀌지 않는데도, 장마다 너비까지 다시 잰 값으로 새로 적힌다.

이 조각은 실제 CSS 선언 한 줄(`left: {x}px;`)을 그대로 보여 준다(자바스크립트·CSS가
곧 주장이라 가상 표기로 옮기지 않았다). 다섯 장·20px 간격은 예로 정한 값이고, 이
모형은 합성이 쓰는 GPU 몫을 시간에 셈하지 않는다.

옆 자리에서 함께 보면 좋은 조각 — 자바스크립트가 값을 **읽어서** 레이아웃을 앞당기는
이야기는 `forced-sync-layout`, 옆 상자를 밀어내는 레이아웃 변화는
`one-grows-rest-shift`, 다시 재지 않고 **옮기기만** 하는 합성 전용 애니메이션은
`move-without-repaint` 가 맡는다.

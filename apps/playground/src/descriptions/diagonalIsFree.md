# 대각선은 공짜다

두 파일을 가장 적은 손질로 맞추는 일을 판 위의 길 찾기로 옮기면, 어느 걸음이 값을 치르고 어느 걸음이 공짜인지가 보인다.

{facet:diagonalIsFree}

가로는 파일 A 의 일곱 줄, 세로는 파일 B 의 일곱 줄이다. 자리 (x, y) 는 A 에서 x 줄, B 에서 y 줄을 지나온 곳이고, (0, 0) 에서 (7, 7) 까지 가면 두 파일을 다 맞춘 것이다. 오른쪽으로 한 칸은 A 의 한 줄을 지우는 것, 아래로 한 칸은 B 의 한 줄을 넣는 것이라 각각 값 1 을 치른다. 두 쪽의 다음 줄이 글자 그대로 같은 칸에는 점선 대각선이 깔려 있고, 그 대각선은 값 없이 지나간다.

화면은 처음 화면을 넣어 여섯 걸음이다. 값 0 걸음을 빼면 한 걸음마다 끝점 하나가 앞 끝점에서 주황 한 칸(값 1)을 치르고, 이어 대각선을 따라 미끄러진다.

- 값 0 에서는 치를 것 없이 (0, 0) 에서 두 칸 미끄러져 (2, 2) 에 선다.
- 값 1 의 두 끝점은 같은 값을 치르고도 간 거리가 다르다. B3 `show n` 을 넣은 쪽은 세 칸을 미끄러져 (5, 6) 까지 가고, A3 을 지운 쪽은 한 칸도 못 미끄러져 (3, 2) 에 머문다.
- 값 2 에서 (5, 6) 에서 뻗은 두 끝점 가운데 A6 `    show i` 를 지운 쪽이 한 칸 미끄러져 끝 (7, 7) 에 닿고, 거기서 멈춘다.

끝에 닿은 경로는 여덟 칸이다. 값을 치른 칸은 둘(넣음 하나, 지움 하나)로 값 D 와 같고, 나머지 여섯 칸은 공짜 대각선이다 — 두 파일이 함께 가진 여섯 줄이다. 오른쪽 장부는 끝점마다 치른 칸과 공짜 칸을 나란히 쌓아, 모든 끝점이 간 칸이 값 4 와 공짜 6 임을 보여 준다.

전제 몇 가지. 줄 단위로, 글자 그대로 견준다 — 앞의 빈칸(들여쓰기)도 줄의 글자다. 비슷한 줄을 한 번에 바꾸는 손질은 없다. 달라진 줄은 지움 하나와 넣음 하나다. 화면의 탐색은 Myers(1986)의 앞으로 가는 탐욕판 그대로다 — 값 D 를 0, 1, 2 로 올리며 대각선 k = x − y 마다 가장 멀리 간 끝점 하나만 남기고, k 는 −D 에서 D 까지 둘씩 걷는다. 두 앞 끝점 가운데 더 멀리 간 쪽에서 뻗고, 끝에 닿으면 같은 값의 남은 끝점은 돌지 않는다. git 의 기본 diff 알고리즘이 Myers 이고, 실제 구현은 양 끝에서 함께 찾아 가운데서 만나는 판 등으로 메모리를 줄인다.

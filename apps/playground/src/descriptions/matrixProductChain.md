# 두 번 뛰기를 행렬 하나로

{facet:matrixProductChain}

두 변환을 잇따라 거는 것을 행렬 하나로 적을 수 있을까? 적을 수 있다면 그 행렬은 두 행렬을 어느 차례로 곱한 것일까?

점 셋 (1, 1) · (2, −1) · (−1, 2) 이 먼저 H = [1 1 ; 0 1] (옆으로 민다) 로 한 번, 이어 S = [1 0 ; 0 2] (세로로 두 배) 로 또 한 번 뛴다. 두 번 뛴 자리는 (2, 2) · (1, −2) · (1, 4) 다. 이어서 두 행렬의 기호가 곱 카드로 날아가 붙어 SH = [1 1 ; 0 2] 가 되고, 점들은 처음 자리에서 SH 로 **한 번에** 뛴다 — 긴 호 셋이 두 번 간 자리에 그대로 내려앉아 같은 점 3 / 3 이다. 마지막으로 두 기호가 엇갈려 자리를 바꾼 HS = [1 2 ; 0 2] 로 뛰면 (3, 2) · (0, −2) · (3, 4) 에 닿아 같은 점 0 / 3 이다.

읽는 법은 하나다. 점은 세로 벡터이고 행렬은 왼쪽에서 곱하므로 **오른쪽에 쓴 것이 먼저 걸린다.** "H 먼저, S 다음" 은 S (H p) = (S H) p 이고, 그래서 두 번 가던 길을 한 번에 가는 행렬은 HS 가 아니라 SH 다. 행렬 곱은 차례를 바꾸면 대개 다른 변환이 된다.

## 전제

- 두 행렬과 점 셋은 **예로 정한 값**이다. 이 화면은 한 사례를 보일 뿐이고, (S H) p = S (H p) 가 모든 행렬 · 모든 점에서 성립한다는 것(곱의 결합 법칙)을 증명하지는 않는다. 차례를 바꾼 곱이 늘 다른 곳에 닿는 것도 아니다 — 서로 바꿔 걸어도 같은 행렬 짝이 있다.
- "같은 곳" 은 좌표가 정수로 정확히 같다는 뜻이다. 이 예의 수는 모두 정수라 셈에 반올림이 끼지 않는다.
- 곱 SH · HS 의 칸은 칸마다 행과 열을 맞물려 셈한 것이다. 그 셈 과정은 이 화면에 두지 않았다.
- 점이 뛰는 곡선은 출발과 도착을 잇는 그림일 뿐이다 — 곡선 위의 중간 자리는 어떤 변환의 값도 아니다.

## 흐름

걸음 여섯(처음 화면 포함)이다. 처음 화면 뒤 걸음마다 1.8 초를 머물고, 뛰기 · 기호가 날아가는 운동이 걸음마다 0.7 ~ 1.6 초 붙어 모두 13.6 초 안팎이다.

1. 처음 — 점 셋과 두 행렬 카드. S 가 왼쪽, H 가 오른쪽이다 (곱을 적는 차례)
2. H 로 한 번 뛴다
3. S 로 또 한 번 뛴다
4. 두 기호가 곱 카드로 날아가 SH 가 된다
5. SH 로 처음 자리에서 한 번에 — 두 번 간 자리와 같은 점 3 / 3
6. 두 기호가 엇갈려 HS 가 되고, 그것으로 한 번에 — 같은 점 0 / 3

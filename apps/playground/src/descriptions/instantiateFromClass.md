## 틀은 하나, 객체는 여럿

클래스 `Counter` 는 값을 담는 것이 아니라 **모양을 정하는 틀**이다. 틀은 "객체마다 `name` 과 `count` 라는
칸이 둘 있다" 는 것만 말한다. `new Counter("red")` 가 불릴 때마다 그 틀에서 새 객체가 하나씩 찍혀 나오고,
찍힌 객체는 틀과 같은 이름의 칸을 제 몫으로 갖는다. 이렇게 틀에서 객체를 만드는 일을 인스턴스화라 한다.

{facet:instantiateFromClass}

### 찍혀 나올 때

`new` 는 먼저 칸 둘을 `null` 로 세운 새 객체를 만들고, 그다음 `create` 를 부른다. `create` 안의
`this` 는 방금 찍힌 그 객체라서 `this.name = name` 과 `this.count = 0` 은 그 객체의 칸에만 값을 넣는다.
세 줄 `let a = …` · `let b = …` · `let c = …` 을 지나면 틀은 여전히 하나이고, 객체는 셋, 이름 a · b · c 가
그 셋을 하나씩 가리킨다. 칸의 이름은 셋이 같고 값은 `"red"` · `"blue"` · `"green"` 으로 저마다 다르다.

### 제 것만 바뀐다

`a.tick()` 은 a 가 가리키는 객체의 `count` 만 하나 올린다. 두 번 부르면 그 칸은 0 → 1 → 2 가 되지만
b 와 c 의 `count` 는 그동안 0 그대로다. `c.tick()` 도 c 의 칸만 0 → 1 로 바꾼다. 그래서 마지막 두 줄
`show a.count` 와 `show b.count` 는 같은 이름의 칸을 읽는데도 `2` 와 `0` 을 보인다. 끝에 남는 것은
a(`"red"`, 2) · b(`"blue"`, 0) · c(`"green"`, 1) — 틀 하나에서 나왔지만 값은 나눠 갖지 않는다.

맨 바깥 줄 하나가 한 걸음이고, `create` · `tick` 의 안쪽 줄은 그 걸음 안에서 일어난다. 시작 화면까지 걸음은
아홉이다.

### 별칭과 반대쪽

이름 둘이 한 목록을 함께 가리키는 별칭(aliasing)에서는 한쪽으로 고친 것이 다른 쪽으로 비쳐 나왔다. 여기서는
이름 셋이 **실체 셋**을 따로 가리키므로 한 객체를 고쳐도 다른 객체에는 아무 일도 없다. 코드는 어느 한 언어가
아닌 읽히는 표기로 적었다.

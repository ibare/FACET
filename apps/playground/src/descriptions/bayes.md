# 베이즈 갱신과 기저율

{facet:bayes}

## 무엇을 보는가

1000 명 가운데 병인 사람이 기저율만큼 있다. 검사는 병이면 90 % 가 양성, 병이 아니어도 10 % 가 양성이다.
같은 검사에서 양성이 연달아 나올 때 "정말 병일 몫" 이 어떻게 오르는지를 한 줄 몫 막대로 본다.
막대의 왼쪽이 병, 오른쪽이 병 아님이고 둘을 더하면 늘 1 이다. 막대 위에는 승산 `병 : 병 아님` 이 정수 쌍으로 뜬다.

양성 하나는 두 박자다.

1. **곱하는 박자** — 양성이 나온 세상으로 좁힌다. 병 쪽은 × 90 %, 병 아님 쪽은 × 10 % 로 줄어 막대 오른쪽에 빈틈이 생긴다.
   병 아님 쪽이 훨씬 크게 준다. 승산은 병 쪽만 × 9 가 된다.
2. **나누는 박자** — 줄어든 두 조각을 그 합으로 나누어 다시 전체 1 로 늘린다. 이것이 양성 뒤의 병일 몫이고, 아래 자취에 점이 하나 는다.

마지막 걸음은 이 판의 자취와 50 % 선을 나란히 두고, 이 기저율에서 절반을 넘는 첫 양성 수를 적는다
(양성 3 번 안에 없으면 그렇게 적는다).

## 손잡이

- **기저율** — 0.1 % · 1 % · 2 % · 5 % · 20 % · 50 % (1000 명 중 병인 사람 1 · 10 · 20 · 50 · 200 · 500).
  돌리면 앞 판의 끝 몫에서 새 기저율로 막대의 나뉨 자리가 미끄러져 옮겨 간다. 0.1 % 에서는 병 쪽이 막대의 천분의 일이라
  거의 선 하나로 보인다 — 몫 그대로 그린다.
- **연달아 양성** — 0 · 1 · 2 · 3. 같은 처음에서 곱 · 나눔 박자가 그 수만큼 이어진다.

| 기저율 | 병일 몫 양성 0 → 1 → 2 → 3 | 승산 (양성 0 → 3) | 절반을 넘는 첫 양성 |
| --- | --- | --- | --- |
| 0.1 % | 0.1 % → 0.9 % → 7.5 % → 42.2 % | 1 : 999 → 729 : 999 | 3 번 안에 없음 |
| 1 % | 1.0 % → 8.3 % → 45.0 % → 88.0 % | 10 : 990 → 7290 : 990 | 3 |
| 2 % | 2.0 % → 15.5 % → 62.3 % → 93.7 % | 20 : 980 → 14580 : 980 | 2 |
| 5 % | 5.0 % → 32.1 % → 81.0 % → 97.5 % | 50 : 950 → 36450 : 950 | 2 |
| 20 % | 20.0 % → 69.2 % → 95.3 % → 99.5 % | 200 : 800 → 145800 : 800 | 1 |
| 50 % | 50.0 % → 90.0 % → 98.8 % → 99.9 % | 500 : 500 → 364500 : 500 | 1 |

어느 기저율에서든 양성 하나마다 승산은 정확히 9 배가 된다. 그런데 출발하는 승산이 작을수록 절반(승산 1 : 1 을 넘는 자리)까지
9 배를 더 여러 번 거쳐야 한다. 50 % 는 처음이 500 : 500 으로 딱 절반이라 "넘었다" 로 치지 않는다 — 넘는 것은 엄격한 비교다.

## 승산 꼴로 읽기

나누는 박자를 잠시 미뤄 두면 셈이 한 줄이 된다.

> 사후 승산 = 사전 승산 × 가능도 비

가능도 비는 "병일 때 양성이 나올 확률 ÷ 병이 아닐 때 양성이 나올 확률" = 90 % ÷ 10 % = 9 다. 사후가 다음 양성의 사전이 되므로
양성 k 번 뒤의 승산은 처음 승산 × 9^k 이다. 계기 **승산 배수**가 1 · 9 · 81 · 729 로 기저율과 무관하게 같은 까닭이다.
승산은 기약하지 않는다 — `90 : 990` 을 `1 : 11` 로 줄이지 않는 것은, 분모 990 이 처음 병 아님 수 그대로 남고 병 쪽만 × 9 되는 것이 보이게 하려는 것이다.
병일 몫은 승산에서 `병 ÷ (병 + 병 아님)` 이고, 화면의 퍼센트는 이것을 천분율 정수로 반올림해 소수 첫째까지 찍은 것이다.

## 전제

- 검사의 90 % · 10 % 와 기저율 여섯은 예로 정한 값이다. 90 % 는 **민감도**(병인 사람을 양성으로 잡는 비율), 10 % 는
  **거짓 양성 비율**(1 − 특이도)이라 부른다.
- 검사끼리 **서로 무관**하다고 둔다 — 같은 사람을 다시 검사해도 앞 결과에 끌리지 않는다. 실제 검사에서는 흔히 깨지는 가정이다.
- 1000 명은 실제로 뽑은 사람이 아니라 **기대 도수**로 센 것이다. 사람 수로 읽는 것은 걸음 0 의 승산(1 % 에서 `10 : 990`)뿐이다.
  양성 하나 뒤 양성인 사람은 평균 병 9 · 병 아님 99 명이고, 화면의 `90 : 990` 은 같은 비를 기약하지 않은 승산이지 사람 수가 아니다.

## 재생

기본 판(1 % · 양성 3)은 걸음 0 을 넣어 여덟 걸음, 약 13.3 초다 (걸음 0 뒤와 곱 · 나눔 걸음마다 1.4 초 + 운동 0.5 초).
양성 0 이면 두 걸음 1.9 초, 1 이면 네 걸음 5.7 초, 2 면 여섯 걸음 9.5 초다. 끝 걸음 뒤에는 손잡이를 기다린다.

## 이어 볼 조각

- **기저율** 조각은 사람 점 1000 개로 이 표의 "양성 1" 열을 센다 — 1 % 에서 양성인 사람 9 : 99 명이 여기서는 같은 비의 승산 90 : 990 으로 뜬다.
- **베이즈 갱신** 조각은 주머니와 공으로 곱하고 나누는 두 박자를 보인다. 그 조각의 가능도 비는 3, 여기는 9 다.
- **조건으로 좁히기** 조각은 36 가지 결과 가운데 조건에 맞는 것만 남긴다. 곱하는 박자가 바로 "양성인 세상으로 좁힌다" 는 그 일이다.

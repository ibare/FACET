## 어디를 얼마나 볼지, 무게로

**어텐션은 점수를 곧장 쓰지 않는다.** 물음 하나가 열쇠마다 매긴 점수는 softmax 를 지나 합이 1 인 무게로 나뉘고, 결과는 값들을 그 무게만큼씩 더한 섞임이다. 가장 잘 맞는 하나를 고르는 것이 아니라, 모두를 조금씩 가져오되 잘 맞는 쪽을 더 많이 가져온다.

{facet:attentionWeights}

### 점수에서 무게로

물음 q = (1, -1) 을 열쇠 넷과 내적하면 -1 · 1 · 0 · -2 다. 벡터 길이 d_k = 2 의 제곱근으로 나누어 점수는 -0.71 · 0.71 · 0.00 · -1.41 이 된다. softmax 는 이 점수를 지수로 키운 뒤 전체 합으로 나눠, 하나였던 1 을 넷으로 쪼갠다 — A 0.13 · B 0.54 · C 0.27 · D 0.06. 점수가 음수여도, 0 이어도 무게는 늘 양수이고 합은 1.00 이다.

### 값이 제 몫만큼 쌓인다

결과는 (0, 0) 에서 시작해 값마다 무게를 곱한 몫을 A · B · C · D 차례로 더한다.

- A 의 몫 0.13·(0, 4) = (0.00, 0.52) → 결과 (0.00, 0.52)
- B 의 몫 0.54·(2, 0) = (1.08, 0.00) → 결과 (1.08, 0.52)
- C 의 몫 0.27·(-1, 1) = (-0.27, 0.27) → 결과 (0.81, 0.79)
- D 의 몫 0.06·(-1, -1) = (-0.06, -0.06) → 결과 (0.75, 0.73)

마지막 결과 (0.75, 0.73) 은 어느 값과도 같지 않다. 그래도 가장 무거운 B 쪽으로 가장 많이 끌려 있다 — 결과에서 값까지의 거리는 B 1.45 가 가장 짧고, C 1.77 · D 2.46 · A 3.36 순이다. 그림은 처음 화면을 넣어 일곱 걸음이다.

### 그림이 줄여 둔 것

- 물음 · 열쇠 · 값은 예로 정한 수이고, 입력에서 투영 행렬로 만드는 단계는 뺐다. 투영으로 한 입력이 셋으로 갈라지는 이야기는 따로 있다.
- 묻는 것은 물음 하나뿐이다. 실제 셀프 어텐션은 모든 토큰이 동시에 묻고, 줄마다 같은 셈을 한다.
- softmax 는 점수의 최댓값을 먼저 빼고 셈한다. 결과는 같고 지수가 넘치지 않게 하는 장치다. 온도는 1 로 두었다.
- 차원은 둘이라 결과를 평면 위의 점으로 그릴 수 있다. 실제 모형의 차원은 수백 이상이다.

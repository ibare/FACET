# 가중합, 그리고 문턱

퍼셉트론은 입력 몇 개를 받아 켜짐(1)과 꺼짐(0) 가운데 하나를 낸다. 하는 일은 두 가지뿐이다 — 입력마다 제 무게를 곱해 한 합에 싣고, 다 실린 뒤 그 합을 문턱과 한 번 견준다.

{facet:weightedSumThreshold}

입력은 x1 · x2 · x3 셋이고 무게는 w1 = 0.60 · w2 = −0.40 · w3 = 0.70, 문턱은 θ = 0.70 이다. 이 무게와 문턱은 **예로 고른 값**이다 — 학습해서 얻은 것이 아니다. 치우침(bias) 항은 따로 두지 않고 문턱 θ 로 말한다.

합은 s = Σ wᵢ·xᵢ 로, i = 1, 2, 3 차례대로 싣는다.

- x1: 0.80 × 0.60 = 0.48 — 합이 0.00 에서 0.48 로 오른다.
- x2: 0.50 × −0.40 = −0.20 — 무게가 음이라 합이 0.28 로 내려간다.
- x3: 0.90 × 0.70 = 0.63 — 합이 0.91 로 오른다.

도중의 합은 문턱과 견주지 않는다. 셋이 다 실린 뒤에 한 번, 0.91 > 0.70 이므로 출력이 0 에서 1 로 건너뛴다. 넘은 폭은 0.21 이지만 그 폭이 얼마든 출력은 1 이다 — 0 과 1 사이의 값은 없다. 합이 문턱과 같거나 낮으면 출력은 0 이다.

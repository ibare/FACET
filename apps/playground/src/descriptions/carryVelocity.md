# 모멘텀은 평지를 이어 받아 건넌다

{facet:carryVelocity}

밀어 주는 기울기가 0 인 평지에서 모멘텀은 멈추는가. 이 조각은 무게 하나 w 를 여덟 번 갱신하며
그 답을 보인다. 갱신 규칙은 `v ← β·v − η·g` 다음에 `w ← w + v` 이고, 기울기 g 는 갱신 전 자리에서 셈한다.

한 번의 움직임 v 는 두 몫의 합이다. **이어 받은 몫** β·v 는 앞 움직임을 조금 줄여 넘겨받은 것이고,
**새로 민 몫** −η·g 는 지금 자리의 기울기가 새로 보탠 것이다. 아래쪽 줄 하나가 갱신 하나이며, 회색이
이어 받은 몫, 노랑이 새로 민 몫이다. 갱신마다 앞 줄의 움직임 전체가 한 줄 내려오며 β 배로 줄어
이어 받은 몫이 되고, 그 끝에서 새로 민 몫이 자란다.

- 처음 세 번은 비탈(g = −1)이라 새로 민 몫이 늘 0.20 이고, 이어 받은 몫이 0.00 → 0.18 → 0.34 로 붙어
  움직임이 0.20 → 0.38 → 0.54 로 커진다. 세 번째 갱신에서 w 는 1.12 로 평지에 들어선다.
- 네 번째부터 일곱 번째까지 네 번은 평지(g = 0)다. 새로 민 몫은 0.00 인데 w 는 1.61 · 2.05 · 2.44 · 2.80 으로
  같은 쪽으로 계속 간다. 움직임은 이어 받은 몫뿐이라 갱신마다 앞의 0.9 배(0.49 · 0.44 · 0.40 · 0.36)로 준다.
- 일곱 번째 갱신에서 평지를 벗어나 다음 비탈에 닿고, 여덟 번째에는 새로 민 몫 0.20 이 다시 붙어
  w 가 3.32, 손실이 1.08 이 된다.

재생은 처음 모습을 넣어 아홉 걸음이다. 한 번도 뒤로 가지 않았다 — 모든 갱신에서 v 가 0 보다 크다.
이어 받지 않았다면(β = 0) 같은 학습률로 w 는 1.20 에 닿은 뒤 평지에서 그대로 멈춘다.

## 전제

- 손실은 **장난감 꺾인 선**이다. w 가 1.1 보다 작으면 L = 3 − w, 1.1 이상 2.5 미만이면 L = 1.9 (평지),
  2.5 이상이면 L = 4.4 − w 이고, 구간 경계는 왼쪽 닫힘이다. 실제 손실 곡면이 이렇게 반듯이 꺾이지는 않는다 —
  기울기가 사라지는 넓은 자리를 가장 짧게 보이려고 고른 모양이다.
- β = 0.9 · η = 0.2 · 처음 w = 0 · 처음 v = 0 은 평지를 넷에 걸쳐 건너도록 손으로 고른 값이다.
- 표시는 소수 둘째 자리다. 줄마다의 세 수(이어 받은 몫 · 새로 민 몫 · v)는 각각 전 정밀도로 셈한 값을 따로
  찍은 것이라, 둘째 자리에서 앞의 둘을 더한 것과 끝자리가 다를 수 있다 (세 번째 갱신의 이어 받은 몫은 0.342 다).

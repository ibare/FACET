# 멈춘 자리만 판정한다

결정적 유한 오토마타(DFA)가 글줄을 받는지 안 받는지는 **글자를 다 먹은 뒤 멈춘 자리** 하나가 정한다. 멈춘 자리가
받는 자리면 받고, 아니면 안 받는다. 도중에 받는 자리를 몇 번 밟고 지나갔는지는 판정에 들지 않는다 — 기계는 지나온
길을 기억하지 않고, 지금 선 자리만 안다.

{facet:acceptState}

## 기계

무늬 `[0-9]+(e[0-9]+)?` — 지수가 붙을 수 있는 수 — 를 알아보는 기계다. 자리 넷, 옮김 다섯. 시작은 A 다.

```
A -[0-9]-> B    B -[0-9]-> B
B -e-> C
C -[0-9]-> D    D -[0-9]-> D
```

겹 동그라미는 받는 자리 B · D 다. B 는 "수 하나가 끝났다", D 는 "지수까지 끝났다" 는 뜻이고, C 는 `e` 를 읽었지만
지수의 수가 아직 없는 자리라 받는 자리가 아니다.

## 걸음

입력은 `120e` 네 글자다. 지수 글자 `e` 는 있는데 지수의 수가 없다. 처음 화면(걸음 0)을 넣어 걸음은 여섯이다.

| 걸음 | 먹은 글자 | 옮김 |
| --- | --- | --- |
| 0 | — | 자리 A 에서 시작 |
| 1 | `1` | A → B (받는 자리) |
| 2 | `2` | B → B (받는 자리) |
| 3 | `0` | B → B (받는 자리) |
| 4 | `e` | B → C |
| 5 | — | 판정: 멈춘 자리 C, 받는 자리가 아니다 → 안 받음 |

글자 넷 가운데 세 걸음을 받는 자리 B 에 섰다. `120` 까지만 보면 받을 글줄이었지만, 마지막 `e` 가 기계를 C 로 옮겼고
입력은 거기서 떨어졌다. 판정은 C 하나로 내려진다.

## 막혀서 안 받는 것과는 다르다

이 기계는 네 글자를 **모두** 먹었다. 어느 글자에서도 옮김이 없어 막히지 않았다. 막힘(정해진 옮김이 없는 글자)도
글줄을 안 받게 하지만, 여기서 안 받는 까닭은 막힘이 아니라 **끝까지 먹고 선 자리**다.

## 어휘 분석기에서는

어휘 분석기는 글줄 전체의 판정이 아니라 가장 길게 맞는 앞머리를 찾으므로, 지나친 받는 자리를 따로 적어 두었다가
막히면 그 자리로 돌아가기도 한다. 그것은 기계 바깥의 기록이다. 기계 자체의 판정은 늘 멈춘 자리 하나로 한다.

## 바늘이 돌며 표시를 지운다

프레임이 모두 찼는데 새 페이지가 들어와야 하면 누군가 나가야 한다. 가장 오래전에 쓰인 페이지를 정확히 골라
내보내면 좋겠지만, 참조가 있을 때마다 쓰인 차례를 다시 매기는 일은 비싸다. **2차 기회**(시계 알고리즘)는 그
대신 페이지마다 **참조 표시** 한 비트만 둔다. 페이지가 쓰이면 표시가 켜진다. 내보낼 페이지를 찾을 때는 바늘이
칸을 한 방향으로 돌며 짚는데, 표시가 켜진 칸은 표시만 끄고 한 번 봐준 뒤 넘어가고, 표시가 꺼진 칸에 닿으면 그
페이지를 내보낸다.

### 짚고, 지우고, 넘어간다

칸은 넷(칸 0~3)이고 바늘은 0 → 1 → 2 → 3 → 0 차례로만 돈다. 처음에는 칸 0 에 페이지 3(표시 켜짐), 칸 1 에
페이지 8(꺼짐), 칸 2 에 페이지 5(켜짐), 칸 3 에 페이지 2(꺼짐)가 있고 바늘은 칸 0 을 가리킨다. 참조는 8 · 6 · 3 · 7
차례로 온다.

| 참조 | 일어난 일 | 바늘 |
| --- | --- | --- |
| 8 | 적중 — 칸 1 표시가 켜진다 | 칸 0 그대로 |
| 6 | 폴트 — 칸 0 · 1 · 2 의 표시를 차례로 끄고 넘어간 뒤, 표시가 꺼진 칸 3 의 2 를 내보내고 6 을 넣는다 | 칸 0 |
| 3 | 적중 — 칸 0 표시가 다시 켜진다 | 칸 0 그대로 |
| 7 | 폴트 — 칸 0 의 표시를 끄고 넘어간 뒤, 표시가 꺼진 칸 1 의 8 을 내보내고 7 을 넣는다 | 칸 2 |

적중일 때 바늘은 움직이지 않는다. 폴트일 때 새로 들어온 페이지는 표시가 켜진 채로 들어가고, 바늘은 그 칸
다음으로 옮겨 간다. 끝에는 칸 0 에 3(꺼짐) · 칸 1 에 7(켜짐) · 칸 2 에 5(꺼짐) · 칸 3 에 6(켜짐)이 남는다. 바늘이
짚은 칸은 모두 여섯, 내보낸 페이지는 2 와 8 둘이다.

### 한 번 살려 두는 것

페이지 3 은 바늘에 두 번 짚혔지만 두 번 다 살아남았다. 첫 번째로 짚혔을 때 표시가 꺼졌지만, 바늘이 다시 오기
전에 참조되어 표시가 도로 켜졌기 때문이다. 반대로 페이지 8 은 첫 바퀴에서 표시가 꺼진 뒤 그사이 쓰이지 않아,
다음에 바늘이 왔을 때 나갔다. 표시는 "바늘이 지난번에 지나간 뒤로 쓰였는가" 만 기억한다. 그 사이 쓰인 페이지는
한 번 더 기회를 얻고, 쓰이지 않은 페이지는 다음 차례에 나간다.

걸음은 처음 장면을 넣어 열하나다(처음 · 적중 둘 · 폴트 알아챔 둘 · 짚음 여섯).

### 이 그림의 모형

칸 넷 · 처음 페이지와 표시 · 참조 넷은 모두 흐름을 보이려고 예로 정한 값이다. 실제 시스템에서는 프레임이 훨씬
많고, 참조 표시는 하드웨어가 페이지 표 항목에 켠다. 여기서는 새로 들어온 페이지의 표시를 켠 채로 넣었고, 적중일 때
바늘은 움직이지 않는다.

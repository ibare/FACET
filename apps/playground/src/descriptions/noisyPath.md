# 흔들리는 길 — 점 하나가 가리키는 방향

확률적 경사 하강은 갱신마다 데이터 전부가 아니라 **뽑힌 점 하나**의 기울기만 보고 무게를 옮긴다.
그 점 하나가 가리키는 방향은 데이터 전체가 가리키는 가장 가파른 내리막과 같지 않다.

{facet:noisyPath}

왼쪽은 무게 (w, b) 의 평면이다. 고리는 같은 전체 손실을 잇는 선이고, 가운데 십자가 그릇의 바닥이다.
갱신마다 지금 자리에서 두 바늘이 선다 — 회색 점선은 전체 데이터의 내리막 −g_전체, 주황은 뽑힌 점 하나의
내리막 −g_점. 둘 사이의 호가 비낀 각이고(도, 반시계 방향이 +), 자리는 주황 쪽으로 η·g_점 만큼 실제로 옮긴다.
오른쪽은 다섯 점과 지금의 선 ŷ = w·x + b 다. 주황 점이 이번에 뽑힌 점이고, 세로 막대가 그 점이 본 틀림이다.
아래 줄은 갱신마다의 비낌(위를 향한 점선이 전체 내리막, 주황 바늘이 이번 방향)과 갱신 뒤 전체 손실을 쌓는다.

걸음은 처음 모습을 넣어 아홉이다(갱신 여덟). 비낌은 33° · −30° · −49° · 35° · 44° · 5° · −135° · −16° 로,
부호가 세 번 바뀐다. 일곱 번째 갱신은 점 0 이 거의 거꾸로(−135°) 가리켜 전체 손실이 0.14 에서 0.18 로
오른다. 그래도 여덟 번 뒤 전체 손실은 처음 4.41 에서 0.13 으로, 삼십분의 일 아래다.

## 전제

- 모형은 ŷ = w·x + b, 점 다섯은 손으로 고른 장난감 데이터다. 처음 (w, b) 는 (0, 0), 학습률 η 는 0.1 이다.
- 점 하나의 손실은 (ŷ − y)², 기울기는 (2r·x, 2r) (r = ŷ − y). 전체 손실과 전체 기울기는 다섯 점의 평균이며
  둘 다 갱신 전 자리에서 셈한다.
- 뽑힌 점의 차례(3 · 0 · 4 · 1 · 2 · 3 · 0 · 1)는 무작위로 뽑는 대신 값으로 고정해 두었다. 묶음 크기는 1 이다.
- 두 축은 같은 축척으로 그려, 화면의 각이 셈한 각과 같다.

# 자리마다 다른 보폭

학습률이 하나뿐이면 모든 무게가 같은 배율로 기울기를 따라간다. 그런데 손실이 어떤 방향으로는 가파르고 어떤 방향으로는 완만하면,
기울기 크기가 자리마다 크게 다르다. 가파른 쪽에 맞춰 학습률을 줄이면 완만한 쪽은 거의 움직이지 않고, 완만한 쪽에 맞춰 키우면
가파른 쪽은 튀어 나간다.

{facet:perParameterStep}

여기서는 무게 둘 a · b 의 손실을 L(a, b) = 5a² + 0.05b² 로 두었다. 한 그릇을 축마다 다르게 늘인 장난감 손실이라, 같은 자리
(1, 1) 에서 a 가 받는 기울기는 10, b 가 받는 기울기는 0.1 — 백 배 차이 난다. 학습률 η = 0.1 하나로 움직였다면 첫 갱신에서
a 는 1.00 을, b 는 0.010 을 움직였을 것이다.

Adam(β1 = 0.9, β2 = 0.999, ε = 1e−8, m · v 는 0 에서 시작)은 자리마다 기울기 제곱의 이동 평균 v 를 따로 쥐고,
보폭 η / (√v̂ + ε) 를 자리마다 따로 쓴다. 기울기가 큰 a 는 보폭이 0.010 으로 좁아지고, 기울기가 작은 b 는 1.00 으로 넓어진다.
보폭이 기울기와 반대로 백 배 벌어지니, 실제 움직임(보폭 · m̂)은 두 자리 모두 0.100 이다.

세 줄은 같은 로그 축을 쓴다. 로그 축에서는 곱하기가 거리 더하기라, "백 배" 가 어디서든 같은 길이로 보인다. 걸음은 처음 모습을
넣어 일곱이고, 한 걸음이 갱신 한 번이다. 여섯 번의 갱신 동안 보폭 비 b / a 는 늘 100 이고, 무게는 두 자리 모두
1.00 에서 0.41 까지 같은 길을 내려간다.

두 움직임이 소수 셋째 자리까지 똑같은 것은 이 손실이 한 그릇을 축마다 늘인 모양이기 때문이다 — Adam 은 축마다의 배율에
무디다. 처음 값 (1, 1) 과 계수는 이 모습을 보이려고 손으로 골랐다.

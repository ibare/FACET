# 스코프와 심볼 테이블

이름을 쓰는 자리에서 컴파일러가 하는 일은 **그 순간 쌓여 있는 표를 맨 위부터 훑는 것**이다. 스코프 규칙은 그 표를
몇 장 쌓을지를 정한다. 같은 열 줄을 세 규칙으로 읽으면 쌓이는 표의 장수가 달라지고, 쓰임에서 뻗은 선이 다른
선언 줄로 옮겨 붙는다.

{facet:scopeAndSymbols}

## 읽는 프로그램

```
let size = 10
let i = 0
function fill(n)
    let size = n * 2
    for i from 1 to n
        let last = i * size
    if n > size
        let size = 0
    return size + last + i
show fill(3) + size + i
```

이름 해석기는 이 글을 위에서 아래로 **한 번** 읽는다. 값을 셈하지 않고, 반복을 되풀이하지 않으며, L10 에서 `fill` 을
불러도 몸으로 뛰어 들어가지 않는다 — 함수 몸은 글에 있는 자리(L4~L9)에서 이미 읽었다.

한 줄마다 차례는 넷이다.

1. 들여쓰기로 몸을 벗어났으면 그 몸의 표를 걷는다
2. 쓰인 이름을 왼쪽부터 찾는다 — 맨 위 표부터 아래로, 처음 만난 선언에서 멈춘다
3. 그 줄의 선언을 규칙이 고른 표에 적는다. 그 표에 같은 이름이 이미 있으면 **두 번 선언**이다 — 걸림으로 세고, 적지 않으며,
   앞 선언이 남는다 (C 계열 언어가 같은 자리의 다시 선언을 거부하는 쪽을 따랐다)
4. 머리줄(`function` · `if` · `for`)이면 규칙에 따라 새 표를 얹고, 인자와 `for` 변수가 그 표에 함께 든다

회차 하나는 11 걸음이다 — 걸음 0(비어 있는 맨 바깥 표 하나) 다음에 줄마다 한 걸음.

## 손잡이 — 스코프 규칙

| 규칙 | 표를 얹는 몸 | 만든 표 | 가장 높이 | 이은 선 | 걸림 |
| --- | --- | --- | --- | --- | --- |
| 블록마다 | `function` · `if` · `for` 몸마다 | 4 | 3 | 11 | 1 — L9 `last` 선언 없음 |
| 함수마다 | `function` 몸만 | 2 | 2 | 12 | 1 — L8 `size` 두 번 선언 |
| 하나뿐 | 맨 바깥 하나 | 1 | 1 | 12 | 3 — L4 `size` · L5 `i` · L8 `size` 두 번 선언 |

쓰임 열둘 가운데 여섯이 규칙에 따라 다른 선언에 닿는다.

- **블록마다 → 함수마다** — 두 선이 옮는다. `for` 몸의 표가 없어져 `i`(L5)와 `last`(L6)가 `fill` 몸의 표에 적히므로,
  L9 의 `i` 선은 L2 에서 L5 로 건너가고, 표 두 장을 다 훑어도 찾지 못하던 L9 의 `last` 는 L6 에 닿는다.
  대신 `if` 몸의 표도 없어져 L8 의 `size` 가 `fill` 몸의 표에서 L4 의 `size` 와 부딪힌다.
- **함수마다 → 하나뿐** — 다섯 선이 옮는다. L4 · L5 · L8 의 선언이 맨 바깥 표의 같은 이름에 부딪혀 튕겨 나오고, 그 선언을
  가리키던 L6 `i` · L6 `size` · L7 `size` · L9 `size` · L9 `i` 가 맨 바깥의 L1 · L2 로 끌려 내려간다.

앞 회차의 선은 걸음 0 에 점선 자국으로 남고, 그 쓰임을 찾는 걸음에서 새 선이 자국 자리에서 새 선언 줄로 휘어 옮겨 간다.
표 더미 쪽에서는 찾기가 맨 위 표부터 한 장씩 내려가며 훑는다 — 블록마다에서 L6 의 `size` 는 위에서 2 장째 표에서 찾고,
L9 의 `last` 는 표 2 장을 모두 훑고 선언 없음이 된다.

## 세 규칙과 실제 언어

- **블록마다** 는 자바스크립트의 `let` 에 가깝다. 자바 · C# 도 블록 스코프이지만, L8 처럼 안쪽 몸이 같은 함수의 지역 이름을
  다시 선언해 가리는 것은 막는다 — 이 화면의 블록마다는 그것을 들인다.
- **함수마다** 는 자바스크립트의 `var` 에 가깝다. 다만 `var` 은 같은 이름의 다시 선언을 조용히 들이는데, 여기서는 걸린다.
  L9 의 `last` 가 블록마다에서는 선언 없음이고 함수마다에서는 L6 에 닿는 것 — 이것이 `let` 과 `var` 의 차이다.
- **하나뿐** 은 옛 BASIC 에 가깝다 — 옛 BASIC 처럼 이름이 모두 한 곳에 든다. 다만 BASIC 에는 선언이 없어 같은 이름을 다시 쓰면
  같은 변수일 뿐 걸리지 않는데, 여기서는 인자와 `for` 변수까지 맨 바깥 표에 들어가 두 번 선언으로 걸린다.

코드 패널의 이름 해석기는 손잡이가 바꾸는 한 함수 `scopeFor` — 선언이 드는 스코프 — 를 가운데 둔다. 쌓인 표를
밟는 화면과 선언 · 쓰임을 번호로 받아 셈하는 코드 패널은 세 규칙 모두에서 같은 선 · 같은 걸림 수를 낸다.

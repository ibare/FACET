# 라운드 로빈 — 차례대로 돌려 보낸다

라운드 로빈 로드 밸런서는 다음 요청을 어느 서버로 보낼지 **차례 표 하나만 보고** 정한다.
요청이 오면 차례 표가 가리키는 서버가 받고, 차례 표는 다음 서버로 한 칸 돈다. 마지막 서버
다음은 다시 첫 서버다.

{facet:spreadInTurn}

서버 셋(A · B · C)에 요청 아홉이 차례로 온다. 처음 화면을 넣어 걸음은 열이다. 원판의 바늘이
차례 표이고, 요청 조각의 너비가 그 요청의 무게다. 무게는 "처리에 드는 일의 크기" 를 예로 정한
단위이고, 서버는 모두 같은 능력이라고 친다.

바늘은 요청이 무거워도 가벼워도 늘 같은 각만큼 돈다. 고르는 식은 "(요청 번호 − 1) 을 서버 수로
나눈 나머지 번째 서버" 와 같아서, 서버가 얼마나 받았는지 · 얼마나 쌓였는지는 입력이 아니다.
그래서 받은 수는 어느 걸음에서나 차이가 1 을 넘지 않고 끝에 3 · 3 · 3 으로 같아진다.

쌓인 무게는 다르다. 끝에 A 는 12, B 와 C 는 4 씩이다(합 20). 이 예에서는 무거운 요청(4 · 3 · 5)이
셋마다 한 번씩 와서 모두 A 에 겹쳤다 — 데이터가 고른 경우다. 요청의 모양이 차례의 주기와
맞물리면 이렇게 한 서버에 몰릴 수 있고, 차례 표는 그 벌어짐을 보지 않는다.

이 모형에는 시간이 없다. 요청이 처리되어 끝나는 일도 없어서 쌓인 무게는 줄지 않는다. 지금 열린
연결 수를 보고 고르는 방식은 다른 이야기다.

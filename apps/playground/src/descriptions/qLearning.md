# Q-러닝과 탐험

{facet:qLearning}

복도 네 칸이 있다. 왼쪽 끝은 **작은 목표**(들어가면 상 +3), 오른쪽 끝은 **큰 목표**(상 +10)이고, 행위자는 둘째 칸에서 출발한다. 출발에서 작은 목표는 한 칸, 큰 목표는 두 칸 떨어져 있다. 행위자 다섯이 이 복도를 판 60 동안 Q-러닝으로 배운다.

## 행위자가 가진 것과 환경이 가진 것

위쪽 띠는 **환경**이다. 어느 칸에 들어가면 상이 얼마인지는 환경만 안다. 아래 다섯 줄은 **행위자**가 가진 것 — 칸마다 "왼쪽으로 가면 얼마" · "오른쪽으로 가면 얼마" 라는 두 값 Q 의 막대와, 출발 칸에서 지금 어느 쪽 값이 더 큰지(탐욕 화살표)뿐이다. 행위자는 상의 표를 읽고 고르지 않는다. 움직여 보고 받은 상으로 제 Q 를 고칠 뿐이다.

한 이동마다 행위자는 이렇게 한다.

- **고르기** — 주사위 u₁ 이 ε 보다 작으면 **탐험**: 주사위를 하나 더 던져 아무 쪽으로나 간다. 아니면 **탐욕**: 지금 칸에서 Q 가 큰 쪽으로 간다. 두 값이 같으면 왼쪽이다.
- **갱신** — 옮겨 간 칸이 끝 칸이면 목표값은 받은 상 r, 아니면 r + γ·(옮겨 간 칸의 큰 쪽 Q). 고른 Q 를 목표값 쪽으로 α 만큼 당긴다. 여기서는 α 0.6 · γ 0.9 로 두었다.

## 무엇을 보는가

처음에는 Q 가 모두 0 이라 두 값이 같고, 동률은 왼쪽이므로 다섯 모두 첫 판에 작은 목표를 밟는다. 그 뒤로는 출발의 왼쪽 값이 3 에 다가가고 오른쪽 값은 0 에 머문다. **ε 이 0 이면 행위자는 오른쪽으로 한 번도 가 보지 않는다** — 큰 상이 있다는 것을 영영 모른다.

ε 을 올리면 가끔 오른쪽으로 비틀거리다 큰 목표를 밟는 행위자가 생긴다. 그러면 큰 상의 값이 먼저 큰 목표 바로 앞 칸의 오른쪽 막대에 서고(10 에 다가간다), 판이 거듭되며 **출발의 오른쪽 막대로 거슬러 번진다**(0.9 × 10 = 9 에 다가간다). 출발의 오른쪽 값이 왼쪽 값 3 을 넘는 순간 탐욕 화살표가 오른쪽으로 돈다.

판 60 뒤 출발 칸의 탐욕이 오른쪽인 행위자 수는 보이는 다섯에서 ε 0 · 0.1 · 0.2 · 0.3 · 0.5 마다 0 · 0 · 2 · 3 · 5 이다. ε 0.1 은 ε 0 과 수가 같지만 막대가 다르다 — 다섯 중 넷은 탐험으로 오른쪽에 다녀온 몫만큼 큰 목표 앞 칸의 왼쪽 값과 출발의 오른쪽 값이 0 을 벗어나 있다(출발의 오른쪽 값 1.57 · 0.87 · 2.22 · 1.99). 남은 하나(행위자 3)는 판 60 동안 오른쪽으로 한 번도 가지 않아 두 값이 0.00 이다. 다섯 모두 판 60 안에 큰 목표까지 닿지는 못했다.

재생은 걸음 0(다섯 모두 출발, Q 모두 0), 판 하나에 한 걸음씩 판 60, 그리고 출발 칸의 탐욕을 읽는 끝 걸음까지 걸음 62 이다. 탐험 ε 손잡이를 돌리면 Q 를 0 으로 되돌리고 같은 씨앗에서 처음부터 다시 배운다.

## 전제

- 복도 · 상 · α · γ · 판 60 은 예로 정한 값이다.
- 행위자 다섯은 저마다 씨앗 하나의 생성기(Park–Miller 최소 표준)를 쓴다. 한 행위자만 보이면 우연을 고른 셈이 되므로, 행위자 이백을 다섯씩 차례로 묶어 "모든 ε 에서 끝 탐욕 오른쪽 수가 이백의 비율 × 5 에서 1 안이고 다수가 같은 쪽" 인 첫 묶음을 골랐다. 이백으로 센 끝 탐욕 오른쪽 수는 ε 마다 0 · 20 · 79 · 154 · 198 이다 — 다섯이 아니라 이백으로 센 값이다.
- 이 복도에서는 판 60 안에 "탐험이 많으면 손해" 가 드러나지 않는다. 그런 주장은 하지 않는다.

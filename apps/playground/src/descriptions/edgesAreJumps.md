# 간선은 뜀이다

{facet:edgesAreJumps}

세 주소 코드를 기본 블록으로 나누고 나면, 블록과 블록은 무엇으로 이어질까. 답은 블록마다 **마지막 명령**에 있다.

그림의 코드는 1 부터 `n` 까지 더하는 반복을 낮춘 것이다.

```
let total = 0
let i = 1
while i <= n
    total = total + i
    i = i + 1
return total
```

낮춘 IR 은 여덟 줄이고, 처음부터 블록 넷으로 나뉘어 있다 — B1(줄 1–2) · B2(줄 3–4) · B3(줄 5–7) · B4(줄 8).
블록을 어디서 자르는지는 다루지 않는다. 여기서는 잘린 블록의 끝에서 선이 어디로 뻗는지만 본다.

걸음은 다섯이다 (처음 화면을 넣어 센다).

1. 시작 — 블록 넷, 간선 없음
2. B1 의 끝, 줄 2 `i = 1` 은 뜀이 아니다. 바로 아래 B2 로 **흘러내린다**
3. B2 의 끝, 줄 4 `ifnot t1 goto L2` 는 갈래가 둘이다. `t1` 이 거짓이면 L2 가 있는 B4 로 뛰고, 참이면 아래 B3 으로 흘러내린다
4. B3 의 끝, 줄 7 `goto L1` 은 L1 이 있는 B2 로 뛴다. 목적지가 출발보다 앞선 블록이라 선이 위로 **거슬러** 오른다
5. B4 의 끝, 줄 8 `return total` 은 아무 데로도 뻗지 않는다

끝나면 간선은 넷이다 — 뜀 둘, 흘러내림 둘, 그 가운데 거슬러 가는 것 하나. 코드에 적힌 뜀 명령은 둘(줄 4 · 줄 7)뿐인데
간선은 넷인 까닭은 흘러내림이 **어떤 명령에도 적히지 않은 간선**이기 때문이다.

코드는 돌리지 않는다. `n` 의 값을 몰라도 간선은 정해진다 — 간선은 실행의 자취가 아니라 코드에 적힌 구조다.
그래서 거슬러 가는 간선도 "몇 번 돈다" 를 말하지 않는다. 되돌아갈 **수 있다**는 것만 말한다.

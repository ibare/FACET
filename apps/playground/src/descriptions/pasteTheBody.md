# 몸통 붙여 넣기

함수를 부르는 대신 그 몸을 부른 자리에 그대로 붙여 넣는 것을 인라이닝이라 한다. 붙여 넣고 나면 부르기가 없으니
인자를 넘길 곳도, 값을 돌려받을 곳도 없다. 그렇다면 인자와 돌려준 값은 어디로 가는가.

## 무엇을 보는가

프로그램은 두 함수, 여섯 줄이다.

```
function cube(x)
    let sq = x * x
    return sq * x
function volume(side)
    let v = cube(side + 1)
    return v
```

왼쪽에 불리는 함수 `cube`, 오른쪽에 부르는 함수 `volume` 이 선다. 붙여 넣을 자리는 L5 `let v = cube(side + 1)` 이다.
처음 화면(걸음 0)을 넣어 모두 4 걸음이다.

- 걸음 1 — 인자 `side + 1` 은 이름도 수도 아닌 식이다. 그래서 부른 줄 앞에 `let x = side + 1` 한 줄이 선다.
  인자 식은 부른 줄의 괄호 안에서, 이름 `x` 는 `cube` 의 머리줄에서 빠져나와 새 줄에서 만난다. 부른 줄은 한 칸 아래로 밀린다.
- 걸음 2 — `cube` 의 몸 줄 `let sq = x * x` 가 부른 자리 앞으로 흘러 들어온다.
- 걸음 3 — `return sq * x` 의 식이 부른 줄로 건너가 `cube(side + 1)` 을 밀어내고 `let v = sq * x` 가 된다. 부르기가 사라진다.

끝에 `volume` 은 `let x = side + 1` · `let sq = x * x` · `let v = sq * x` · `return v` 네 줄이다(몸 줄 2 → 4).
`cube` 의 세 줄 L1~L3 은 제자리에 그대로다. 붙은 세 줄마다 어느 줄에서 왔는지 잇는 점선이 남는다.

## 인자는 한 번만 묶는다

`x` 는 `cube` 의 몸에서 세 번 쓰인다. 쓰는 자리마다 `side + 1` 을 베껴 넣으면 `(side + 1) * (side + 1)` 처럼 같은 덧셈을
세 번 하게 된다. 그래서 식인 인자는 매개변수 이름에 **한 번** 묶고, 몸에서는 그 이름을 쓴다. 인자가 처음부터 이름이나 수였다면
줄을 세우지 않고 매개변수 자리에 그대로 바꿔 넣었을 것이다.

셈은 앞뒤가 같다. 연산은 붙이기 전에도 뒤에도 셋(`+` 하나 · `*` 둘)이고, `volume(2)` 는 둘 다 27 이다. 달라진 것은 부르기
하나가 없어졌다는 것뿐이다(부르기 1 → 0).

## 돌려준 값은 받는 이름으로 간다

`return` 은 부른 쪽으로 값을 돌려보내는 문이다. 몸이 부른 자리에 들어오면 돌려보낼 곳이 따로 없으니, `return` 의 식은
부른 줄이 값을 받던 이름 `v` 의 오른쪽으로 곧장 간다. 값을 한 번 더 옮겨 담는 줄은 두지 않는다.

`cube` 의 정의를 지우지 않는 것은 다른 곳에서 또 부를 수 있어서다. 더는 부르는 곳이 없는 정의를 지우는 것은 다른 변환이 한다.

## 전제

이것은 컴파일러가 인라이닝을 하는 한 방식을 보인 것이다. 실제 컴파일러는 붙여 넣은 뒤 다른 변환(상수 접기 · 쓰이지 않는 줄
지우기 등)을 여러 번 섞어 돌린다. 여기의 데이터에는 이름 겹침이 없다 — `cube` 의 이름 `x` · `sq` 와 `volume` 의 이름 `side` · `v` 가
다르다. 겹쳤다면 붙여 넣는 쪽 이름 뒤에 `2` 를 붙여 갈랐을 것이다.

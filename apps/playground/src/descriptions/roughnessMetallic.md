## 재질은 값 둘로 정해진다

**물리 기반 렌더링(PBR)은 재질을 금속성과 거칠기 두 값으로 적는다.** 금속성은 번쩍임이 어떤 색을 띠고 퍼진빛이 남는지를, 거칠기는 번쩍임이 면 위에서 얼마나 넓게 번지는지를 정한다. 같은 면 · 같은 빛 · 같은 눈 앞에서 값을 하나씩만 바꾸면 그 두 몫이 따로 보인다.

### 무엇을 셈하는가

평평한 면 위에 점 아홉(x = −4 … 4)이 있고, 빛은 (−3, 4), 눈은 (3, 4) 에 있다. 바탕색은 금빛 (1.00, 0.71, 0.29) 이다. 점마다 퍼진빛과 번쩍임을 셈해 더한 것이 그 점의 값이고, 칸은 그 값을 칠한 색이다. 재질은 네 번 얹힌다 — 처음 화면까지 걸음은 다섯이다.

- **금속성 0, 거칠기 0.4** — 퍼진빛이 바탕색을 띤다(x = 0 에서 (0.768, 0.545, 0.223)). 번쩍임은 세 채널이 같은 무색이고, 봉우리 x = 0 에서 0.473 이다.
- **금속성 0 → 1** — 퍼진빛이 모든 점에서 0 이 되고, 번쩍임이 바탕색으로 물든다. 봉우리의 번쩍임은 (11.733, 8.332, 3.405) 다.
- **거칠기 0.4 → 0.6 → 0.8** — 봉우리(빨강)가 11.733 → 2.208 → 0.683 으로 낮아지고, 봉우리의 절반 이상인 점이 1 → 3 → 7 로 늘어난다.

마지막 걸음에서 봉우리는 거울 자리 x = 0(0.654)에서 빛 쪽 x = −1(0.683)로 한 점 옮는다. 번쩍임이 넓게 번지면 빛을 더 곧게 받는 쪽(N·L 이 큰 쪽)의 몫이 이긴다.

### 모형과 전제

- 번쩍임은 쿡-토런스 꼴이다 — 미세면 분포 D 는 GGX, 가림 G 는 Smith 의 Schlick-GGX(k = α/2), 반사율 F 는 Schlick 근사다. α = 거칠기² 로 둔다.
- 금속이 아닌 면의 수직 반사율 F0 는 0.04, 금속은 바탕색 자체다. 퍼진빛은 (1 − F)(1 − 금속성) 만큼만 남는다 — 금속은 퍼진빛이 없다.
- 빛의 세기는 E = π 로 두어 흰 램버트 면이 빛을 정면으로 받으면 1 이 되게 했다. 거리에 따른 감쇠는 없다.
- 값은 자르지 않은 선형 값이라 1 을 넘는다(11.733). 칠할 때만 채널마다 값/(1 + 값) 으로 눌러 담는다. 감마 보정은 하지 않는다.
- 면 위 공중의 윤곽은 점마다의 번쩍임(빨강)을 같은 눌러 담기로 높이로 옮긴 것이다. 방향마다의 분포가 아니라 **면 위 자리마다**의 값이다.

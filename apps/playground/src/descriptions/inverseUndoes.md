# 역행렬은 점을 제자리로 돌린다

행렬로 옮긴 점들을 제자리로 돌려놓는 행렬은 무엇이며, 걸면 정말 돌아오는가.

{facet:inverseUndoes}

점 셋 (1, 2) · (−2, 1) · (1, −1) 이 저마다 제자리에 빈 고리를 남겨 두고 서 있다. 행렬 A = [3 1 ; 1 1] 을 걸면
점은 (5, 3) · (−5, −1) · (2, 0) 으로 떠나고, 고리와 점 사이에 줄이 당겨진다. 셋 모두 떠났다.

다음 걸음에서 A⁻¹ 를 셈한다. det A = ad − bc = 2 이고, A 의 칸에서 a 와 d 가 자리를 맞바꾸고 b 와 c 의 부호가 뒤집혀
[1 −1 ; −1 3] 이 된다. 이것을 det 로 나누면 A⁻¹ = 1/2 · [1 −1 ; −1 3] = [0.5 −0.5 ; −0.5 1.5] 다.

A⁻¹ 를 옮긴 점 셋에 걸면 점이 줄을 되감으며 고리 안으로 들어간다. 도착한 자리는 (1, 2) · (−2, 1) · (1, −1) —
떠나기 전 자리와 정확히 같아 제자리로 온 점은 3 / 3, 남은 거리는 0 이다. 마지막 걸음은 A⁻¹ 와 A 를 한 행렬로 적는다.
A⁻¹A = [1 0 ; 0 1] 이고, 이 행렬이 옮기는 점은 0 / 3 이다.

화면은 처음 화면을 넣어 걸음 다섯이다.

## 밝혀 둘 것

- 행렬 A 와 점 셋은 예로 정한 값이다. 한 사례가 모든 점에서 성립함을 증명하지는 않는다 — 다만 A⁻¹(A p) = (A⁻¹A) p = p 이므로
  어느 점을 골라도 같은 일이 일어난다.
- 점이 떠나고 돌아오는 도중의 곧은 길은 그림일 뿐이다. 행렬은 출발 자리에서 도착 자리를 정할 뿐 그 사이의 길을 정하지 않는다.
- 이 수들은 정수이거나 0.5 의 배수라 셈에 반올림이 끼지 않는다. "돌아왔다" 는 좌표가 정확히 같다는 뜻이다.

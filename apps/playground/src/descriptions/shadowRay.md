# 그림자 광선

같은 바닥 위의 점인데 어떤 점은 빛을 받고 어떤 점은 그림자다. 바닥의 기울기는 어디서나 같다 — 갈리는 것은
점에서 빛까지 가는 **길이 막혔는가** 하나다.

{facet:shadowRay}

## 무엇을 보나

한 판은 걸음 여섯이다 (걸음 0 을 넣어 센다). 처음에는 바닥 y = 0 위의 점 다섯, 점광 (0, 4), 그 사이의 공과 빛보다
높이 뜬 풍선이 선다. 걸음마다 점 하나에서 빛 쪽으로 광선이 자라 나간다. 왼쪽은 옆에서 본 모습이고, 오른쪽은 같은
광선을 곧게 편 줄이다 — 0 에서 빛까지 거리 d 까지가 빛까지의 길이다.

- 점 1 · 점 2 의 광선은 공에 걸려 멎는다 (t 2.25 < d 5.00 · t 1.82 < d 4.27). 공 뒤의 길은 점선으로 남고, 그 점의 빛은 0 이다.
- 점 3 · 점 4 의 광선은 아무것에도 닿지 않고 빛에 이른다 (d 4.00 · d 4.27). 빛은 1 이다.
- 점 5 의 광선은 빛을 **지나** 풍선에 닿는다 (t 7.00). 그러나 d 5.00 보다 멀어 길 밖이다 — 빛은 1 이다.

끝에는 빛 받음 3 · 그림자 2 가 남는다.

## 이 그림이 정해 둔 것

- **2 차원 옆모습이다.** 공과 풍선은 원, 빛은 크기 없는 점광 하나다. 그래서 그림자의 가장자리가 흐려지지 않는다.
- **밝기는 보임 0 / 1 만 센다.** 면의 기울기(N·L)를 곱하지 않는다 — 바닥의 법선이 모두 (0, 1) 로 같아도 밝기가 갈린다는
  것이 이 그림의 말이다. 실제 셰이딩은 이 보임에 기울기와 거리를 더 곱한다.
- **가장 가까운 것을 고를 필요가 없다.** 빛 앞에서 무엇이든 하나만 맞으면 그림자다. 그림은 풍선이 가리지 않음을 보이려고
  두 물체를 모두 시험해 t 를 보여 준다.
- 광선의 t 는 ε = 0.0001 보다 큰 것만 센다. 바닥 자신은 시험하지 않는다 — 바닥에서 위로 떠나는 광선이 바닥과 만나는 곳은
  t = 0 뿐이라 어차피 버려진다.

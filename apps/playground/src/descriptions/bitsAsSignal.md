## 비트는 선 위에서 뒤집힘이 된다

선에는 0 과 1 이 없다. 있는 것은 시간을 따라 달라지는 전압뿐이다. 가장 쉬운 생각은 1 이면 높게, 0 이면
낮게 전압을 그대로 두는 것이다. 그런데 같은 비트가 길게 이어지면 선은 한 값에 머문 채 아무 일도 일어나지
않는다. 받는 쪽은 그 사이에 비트가 몇 개 지나갔는지를 제 시계로만 세야 하고, 시계가 조금만 어긋나도 비트를
하나 더 세거나 덜 센다. 선이 멈추지 않게 하려면 어떻게 실어야 할까.

### 비트마다 가운데서 한 번

맨체스터 부호는 비트 하나를 반 칸 둘로 나눈다. 1 은 **낮음 → 높음**, 0 은 **높음 → 낮음** 이다
(IEEE 802.3 이더넷의 약속). 그래서 모든 비트의 한가운데에서 전압이 반드시 뒤집히고, **뒤집히는 방향이 곧
비트**다 — 위로 가면 1, 아래로 가면 0. 받는 쪽은 이 가운데 뒤집힘에 제 시계를 맞춘다.

같은 비트가 이어지면 앞 비트는 끝자리에, 이번 비트는 반대 자리에서 시작해야 한다. 0 다음 0 이면 앞 비트는
낮음으로 끝났는데 이번 비트는 높음으로 시작해야 한다. 그래서 두 비트의 경계에서도 한 번 더 뒤집힌다.
비트가 바뀌는 자리(0 다음 1)에서는 선이 이미 시작할 자리에 있어 경계 뒤집힘이 없다.

### 이 예에서

문자 `A` 는 바이트 `0x41`, 비트로는 `0 1 0 0 0 0 0 1` 이다. 한 걸음에 비트 하나를 싣고, 걸음은 시작을
합쳐 아홉이다. 반 칸 열은 `HL LH HL HL HL HL HL LH` 가 되어, 가운데 뒤집힘이 8, 경계 뒤집힘이 4 — 네 번째부터
일곱 번째 비트까지, 0 이 이어지는 자리다. 모두 12 번 뒤집힌다.

아래 줄은 같은 비트를 전압 그대로 실은 것이다. 뒤집힘은 비트가 바뀌는 경계에서만 생겨 3 번뿐이고, 세 번째부터
일곱 번째까지 0 다섯 개가 지나가는 동안 선은 낮음에 머문다. 맨체스터 줄은 같은 자리에서도 비트마다 뒤집힌다.
그 값으로 뒤집힘은 네 배 늘었다 — 같은 비트를 보내는 데 선을 더 자주 흔들어야 하는 것이 맨체스터의 값이다.

### 줄여서 보인 자리

- 비트는 **높은 자리부터** 싣는다. 실제 이더넷은 바이트의 낮은 자리부터 보내지만, 적힌 비트 열과 선의 차례를
  같게 해서 읽기 쉽게 했다.
- 전압은 높음과 낮음 두 값으로만 그렸다. 실제 전압의 크기와 첫 비트 앞의 경계는 다루지 않는다.

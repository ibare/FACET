# 큐잉 모델

{facet:queueingModel}

기다림은 부하만으로 생기지 않는다. **들쭉날쭉함**이 만든다. 서버 하나에 요청 마흔이 먼저 온 차례로 들어온다.
도착 간격과 처리 시간이 모두 고르면 부하 ρ = 0.9 에서도 아무도 기다리지 않는다. 같은 ρ 에서 들쭉날쭉을
반쯤 · 지수로 올리면 기다린 요청과 기다림이 는다.

## 무엇을 보는가

- **시간 띠** 위의 점 마흔이 요청의 도착 시각이다. 걸음마다 하나가 도착해 칠해진다.
- 점 위로 자라 오르는 **막대**가 그 요청의 기다림이다. 기다리지 않은 요청은 막대가 없다.
- 띠 아래 **처리** 길에는 처리 막대가 시작에서 떠남까지 그어진다. 막대 사이의 틈이 서버가 논 때다.
- 맨 아래는 그 요청이 도착한 순간의 **서버와 줄**이다. 서버가 처리 중이면 새 요청(노란 표지)은 줄 끝에 서고,
  비어 있으면 곧장 서버로 들어간다.
- 마지막 걸음은 모아 셈이다. 평균 기다림을 점선으로 긋고, 평균 · 가장 긴 기다림을 캡션에 적는다.
  계기는 기다린 요청 수(`waited`)와 가장 긴 줄(`longest-line`)이다.

## 손잡이

- **들쭉날쭉** — 고름 · 반쯤 · 지수. 돌리면 점들이 뭉쳤다 흩어진다. 고름은 같은 간격이고, 지수는 몰린 도착 무리가 생긴다.
- **부하 ρ** — 0.5 · 0.7 · 0.8 · 0.9. 도착 간격의 평균이 1/ρ 라, 올리면 같은 점들이 왼쪽으로 좁혀 모이고 좁혀진 곳에서 막대가 솟는다.

시간 띠의 끝은 두 손잡이의 모든 조합 가운데 가장 늦은 떠남(86.52)으로 고정했다. 그래서 손잡이를 돌리면 축이 그대로인 채 점이 옮겨 간다.

## 이 데이터에서 센 것 (요청 40 · 씨앗 42)

| 들쭉날쭉 | ρ 0.5 | ρ 0.7 | ρ 0.8 | ρ 0.9 |
| --- | --- | --- | --- | --- |
| 고름 — 평균 기다림 · 기다린 요청 | 0.00 · 0 | 0.00 · 0 | 0.00 · 0 | 0.00 · 0 |
| 반쯤 — 평균 기다림 · 기다린 요청 | 0.01 · 2 | 0.07 · 12 | 0.18 · 18 | 0.32 · 25 |
| 지수 — 평균 기다림 · 기다린 요청 | 0.75 · 19 | 1.06 · 24 | 1.24 · 25 | 1.77 · 29 |

가장 긴 줄은 고름 0, 반쯤 0~1, 지수 3~4 이다. 이 데이터의 네 ρ 모두에서 고름 < 반쯤 < 지수였고, 씨앗을 7 · 99 · 1234 · 31337 로 바꿔도
같은 차례였다. 반쯤 · 지수에서 ρ 를 올리면 평균 기다림과 기다린 요청이 는다 — 같은 난수 열을 1/ρ 로 늘이고 줄이기 때문이다.

## 코드 패널

기다림은 린들리(Lindley) 점화식으로 센다. 요청 i 의 기다림은 w₀ = 0, wᵢ = max(0, wᵢ₋₁ + 처리ᵢ₋₁ − 간격ᵢ) 이다.
앞 요청이 남긴 일(기다림 + 처리)에서 이번 간격만큼 줄어든 것이 이번 요청이 기다릴 몫이다. 화면의 막대 높이가 이 w 다.
줄은 요청 i 가 도착한 때 앞선 요청 가운데 아직 시작하지 않은 수로 센다. 코드 패널은 max 를 "음수면 0 으로 자른다" 로 풀어 적었다.
난수 뽑기는 코드 패널 밖에서 하고 간격 · 처리를 배열로 건넨다.

## 모형이 정한 것

- 시각은 **단위 시간**이다 — 처리 평균을 1 로 둔 예로 정한 단위다. 망 지연은 0 으로 둔다.
- 난수는 x ← (75·x + 74) mod 65537, **씨앗 42** 의 생성기로 뽑고 u = x / 65537 이다. 요청마다 u 를 둘 뽑는다 — 먼저 간격, 다음 처리.
  손잡이를 어느 값으로 돌려도 같은 u 열을 쓴다.
- **고름**은 간격 · 처리가 늘 평균이다. **반쯤**은 평균의 0.5~1.5 배 사이에서 고르게 뽑는다. **지수**는 −ln(1 − u) × 평균 — 포아송 도착과
  지수 처리, 곧 M/M/1 의 모양이다.
- M/M/1 식의 줄에서 기다리는 평균 ρ/(1−ρ) 는 1.0 · 2.33 · 4.0 · 9.0 이지만, 여기의 평균(0.75 ~ 1.77)은 요청 마흔의 한 표본이라 식과 다르다.
  식은 긴 시간의 평균이고 이 화면은 표본 하나다.
- 서버는 하나, 먼저 온 차례다. 줄에 한도가 없다. 처리 중인 하나는 줄에 세지 않는다.
- 같은 시각 도착은 번호 차례로 두지만 이 데이터에서는 일어나지 않는다.

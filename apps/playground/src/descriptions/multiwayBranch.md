## 다중 분기 — 위에서부터 묻는다

조건이 여럿 늘어선 `if` / `else if` / `else` 사슬에서 흐름은 조건을 **위에서부터 하나씩** 묻는다. 거짓이면 다음 조건으로 내려가고, **처음 참인 조건**에서 그 갈래로 빠져나간다. 그 아래 조건들은 셈해 보면 참이더라도 **묻지도 않는다.**

{facet:multiwayBranch}

### 무엇을 보나

- 점수 `74` 로 성적을 매기는 다섯 갈래 사슬이다. 흐름(구슬)은 조건 머리줄마다 선 문짝에 멈춘다.
- `74 >= 90` · `74 >= 80` 은 거짓 — 문짝이 아래로 열리고 구슬은 다음 조건까지 떨어진다.
- `74 >= 70` 은 참 — 문짝은 닫힌 채 구슬이 옆문으로 굴러 나가 `grade = "C"` 를 밟는다.
- 갈래를 마친 흐름은 오른쪽 난간을 타고 사슬 아래 `show grade` 로 합류한다. 그 사이 `else if score >= 60` 은 묻지 않은 채 지나쳐진다 — `74 >= 60` 도 참이지만 차례가 오지 않았다.

### 요점은 차례다

- 조건이 서로 겹치면(74 는 `>= 70` 이기도 하고 `>= 60` 이기도 하다) **먼저 적힌 쪽이 이긴다.** 그래서 이런 사슬은 좁은 조건을 위에 둔다. 순서를 뒤집어 `>= 60` 을 맨 위에 두면 70 점도 90 점도 모두 `"D"` 가 된다.
- `else` 는 조건이 아니다. 위의 조건이 모두 거짓일 때만 그 몸으로 간다.
- `grade` 는 사슬 **앞에서** `let grade = ""` 로 만들어 둔다. `let` 으로 만든 이름은 그 몸 안에서만 살기 때문에, 갈래 안에서 처음 만들면 사슬 뒤의 `show grade` 가 쓸 수 없다.
- `match` 나 다른 언어의 `switch` 처럼 값으로 곧장 뛰는 분기와 다르다. `if` / `else if` 사슬은 매번 위에서부터 묻는다.

### 걸음

시작 · `let score = 74` · `let grade = ""` · `if score >= 90`(거짓) · `else if score >= 80`(거짓) · `else if score >= 70`(참) · `grade = "C"` · `show grade` — 여덟 걸음. 조건 넷 가운데 셋을 물었고, 출력은 `C` 다.

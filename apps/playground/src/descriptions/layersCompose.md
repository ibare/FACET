# 층을 겹치면 경계가 굽는다

ReLU 단위 하나는 입력 평면에 **곧은 꺾임선** 하나를 긋는다. 선 한쪽에서는 0 이고 다른 쪽에서는 곧게 오르는 값을 낸다. 이런 단위만으로는 곧은 선밖에 그을 수 없을 것 같은데, 둘째 층이 단위들의 값을 더하면 켜짐과 꺼짐을 가르는 경계가 굽는다.

{facet:layersCompose}

입력은 x = (x₁, x₂) 이고 평면은 [−2, 2] × [−2, 2] 이다. 첫 층의 단위 셋은 다음과 같다.

- h₁ = max(0, x₁ − 0.5·x₂)
- h₂ = max(0, −x₁ − 0.5·x₂)
- h₃ = max(0, x₂ − 1)

둘째 층은 o = −1 + h₁ + h₂ + h₃ 이고, o 가 0 을 넘으면 켜짐이다. 이 무게와 치우침은 **예로 고른 값**이다 — 학습해서 얻은 것이 아니다. 망은 앞으로 셈만 하고, 단위를 합에 넣는 차례만 바뀐다.

재생은 처음 모습을 넣어 네 걸음이다.

1. 합에 단위가 없다. 평면 어디서나 o = −1 이라 경계가 없다.
2. h₁ 을 더한다. 경계가 평면의 오른쪽 아래 귀퉁이에서 밀려 들어와 (0, −2) 에서 (2, 2) 로 가는 곧은 선이 된다. 모서리는 0.
3. h₂ 를 더한다. 두 단위가 함께 켜진 아래쪽 띠에서 경계가 x₂ = −1 로 눕고, 양 끝 (−0.5, −1) · (0.5, −1) 에서 꺾인다. 모서리는 2.
4. h₃ 을 더한다. x₂ = 1 위쪽에서 경계가 한 번 더 꺾여 (−1.5, 1) · (1.5, 1) 에 모서리가 생긴다. 모서리는 4 이고, 경계는 원점을 감싸는 그릇 모양이다.

모서리는 모두 어느 단위의 꺾임선(점선) 위에 있다. 켜짐 무늬 — 어느 단위가 0 보다 큰가 — 가 같은 영역 안에서는 o 가 x 의 일차식이라 경계가 곧고, 영역이 바뀌는 꺾임선에서만 방향을 바꿀 수 있기 때문이다. 단위를 더할 때마다 운동은 그 단위의 무게를 0 에서 1 까지 키우며 경계가 옮겨 가는 모습을 보인다.

평면 위 네 자리는 움직이지 않는다. 끝 걸음에서 원점 (0, 0) 은 o = −1.00, 위쪽 (0, 1.5) 는 −0.50 으로 꺼져 있고, 아래쪽 (0, −1.5) 와 오른쪽 (1.5, 0) 은 0.50 으로 켜져 있다 — 그릇 안쪽이 꺼진 쪽이다. 점이 옮겨 가는 것이 아니라 경계가 모양을 바꾼다.

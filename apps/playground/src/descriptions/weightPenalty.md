# L1 · L2 정규화 — 벌점의 모양

같은 세기로 벌점을 걸어도 L1 과 L2 는 무게를 다르게 줄인다. L1 은 작은 무게부터 하나씩 **정확히 0 에 붙이고**,
L2 는 여섯을 **같은 비율로 오그릴 뿐** 누구도 0 에 닿게 하지 않는다. 이 화면은 그 차이를 무게 여섯의 자리로 보인다.

{facet:weightPenalty}

## 무엇을 보는가

줄 하나가 무게 하나다. 가운데 세로선이 0, 빈 고리가 출발 자리 a, 찬 점이 지금의 w 이고, 고리에서 점까지의 선이
벌점이 깎아 낸 거리다. 오른쪽 두 열은 지금 무게 w 와 비 w / a 다.

한 판은 걸음 12 개다 — 걸음 0 은 출발(무게 = a, 0 인 무게 0 개), 걸음 1 ~ 10 은 갱신 1 ~ 10, 걸음 11 은 정확히 0 인
무게를 세는 걸음이다. η 는 0.4 로 고정이다.

- **L1** — 갱신 한 번이 두 마디다. 먼저 a 쪽으로 당긴 값 h = w − η·(w − a) 를 얻고, h 가 0 둘레의 띠 |h| ≤ ηλ 안에
  들면 w 를 0 으로 둔다. 띠 밖이면 크기와 상관없이 같은 폭 ηλ 만큼 0 쪽으로 옮긴다. 0 에 닿은 무게는 네모로 바뀌어
  그 자리에 머문다.
- **L2** — 한 줄이다. w ← w − η·(w − a) − η·λ·w. 띠가 없고, 여섯 줄의 w / a 가 매 갱신 같은 수를 보인다.

## 손잡이를 돌리면

벌점 세기 λ 를 돌리면 무게 여섯이 앞 판의 끝 자리에서 a 로 돌아간 뒤 새로 미끄러진다. L1 이면 띠의 폭이 새 ηλ 로
펴지거나 접힌다.

갱신 열 번 뒤 정확히 0 인 무게의 수:

| λ | 0 | 0.1 | 0.3 | 0.5 | 0.8 | 1.2 |
| --- | --- | --- | --- | --- | --- | --- |
| L1 | 0 | 1 | 3 | 4 | 5 | 6 |
| L2 | 0 | 0 | 0 | 0 | 0 | 0 |

L1 에서 λ 를 올리면 0 에 붙는 무게가 늘고, 붙는 갱신도 앞당겨진다 — λ 0.3 에서는 w6 · w5 · w4 가 갱신 1 · 2 · 4 에,
λ 1.2 에서는 w6 ~ w3 이 갱신 1 에, w2 가 갱신 2 에, w1 이 갱신 5 에 붙는다. 기본값 L1 · λ 0.5 에서는 끝 무게가
0.60 · -0.20 · 0.00 · 0.00 · 0.00 · 0.00 이다.

같은 λ 에서 벌점을 L2 로 돌리면 0 에 붙어 있던 무게들이 작게 남은 무게로 떨어져 나온다. λ 0.5 의 L2 끝 무게는
0.73 · -0.47 · 0.30 · -0.17 · 0.12 · -0.05 이고, 여섯 모두 w / a = 0.67 이다. 끝의 w / a 는 λ 사다리를 따라
1.00 · 0.91 · 0.77 · 0.67 · 0.56 · 0.45 다.

λ 0 칸은 기준선이다. 두 벌점 모두 무게가 움직이지 않는다 — 시작 무게가 벌점 없는 손실의 바닥이기 때문이다.

화면의 무게는 소수 둘째 자리로 적되, 정확히 0 이 아닌데 둘째 자리로 0.00 이 되는 무게는 셋째 자리까지 적는다
(L1 λ 0.1 의 갱신 3 에서 w6 = -0.002, λ 0.8 의 갱신 4 에서 w2 = -0.004). 0.00 은 정확한 0 에만 뜬다.

## 전제

모형은 특징이 서로 겹치지 않는 선형 회귀로 줄였다 — 데이터 손실이 ½·Σ(w − a)² 라 무게마다 따로 셈할 수 있다.
시작 무게는 벌점 없이 맞춘 자리 a = [1.10, -0.70, 0.45, -0.26, 0.18, -0.08] 로 두었다.
L1 의 판정 |h| ≤ ηλ 에서 두 쪽이 같아지는 자리는 이 데이터의 어느 조합 · 어느 갱신에도 없다(차가 늘 1e-9 보다 크다) —
같아지면 알고리즘은 한쪽을 지어 고르지 않고 멈춘다.

## 코드 패널

`penalize(a, w, n, kind, lam, eta, steps)` 는 화면과 같은 차례로 셈해 끝에서 0 인 무게의 수를 돌려준다. 걸음 0 에서는
패널이 꺼지고, L1 갱신 걸음은 그 갱신에 새로 0 에 닿은 무게가 있으면 `w = 0` 줄이, 없으면 두 끌기 줄이 켜진다.
L2 갱신 걸음은 한 줄 갱신이, 마지막 걸음은 세는 줄이 켜진다.

# 유도 트리

{facet:derivationTree}

`let x = a + b + 1` 을 장난감 문법 다섯 규칙으로 유도한다. 규칙 하나를 펼칠 때마다 한 줄을 고쳐 쓰는 대신,
펼친 기호를 **그 자리에 남기고** 규칙의 몸을 그 아래 자식으로 매단다. 그렇게 모은 자취가 유도 트리다.

- 문법 (예로 만든 장난감 문법 — 시작 기호는 `Stmt`)
  - R1 `Stmt → let NAME = Expr`
  - R2 `Expr → Expr + Term`
  - R3 `Expr → Term`
  - R4 `Term → NAME`
  - R5 `Term → NUM`
- 입력: 토큰 8 — `LET let` · `NAME x` · `OP =` · `NAME a` · `OP +` · `NAME b` · `OP +` · `NUM 1`

펼치는 차례는 **가장 왼쪽 유도**다 — 펼칠 비단말이 여럿이면 가장 왼쪽 것부터. 유도는 알고리즘이 문법과 토큰 열에서 직접 찾는다.

## 걸음 (처음 화면을 넣어 9)

1. 처음 — 뿌리 `Stmt` 하나
2. R1 — `Stmt` 아래에 `let NAME = Expr` 넷
3. R2 — `Expr` 아래에 `Expr + Term`
4. R2 — 그 아래 `Expr` 아래에 다시 `Expr + Term`
5. R3 — 가장 깊은 `Expr` 아래에 `Term`
6. R4 — 그 `Term` 아래에 `NAME` (a)
7. R4 — 둘째 `Term` 아래에 `NAME` (b)
8. R5 — 첫 `Term` 아래에 `NUM` (1)
9. 잎 읽기 — 잎을 왼쪽부터 읽으면 `let NAME = NAME + NAME + NUM`, 토큰 8 과 차례대로 모두 맞는다

## 모양이 말하는 것

다 지은 나무는 노드 15 (안쪽 7 + 잎 8), 층 6 이다. 왼쪽 재귀 규칙 `Expr → Expr + Term` 때문에 `Expr` 아래 첫 자식이 또 `Expr` 라,
`Expr` 세 개가 사슬로 이어져 가지가 **왼쪽 아래로** 뻗는다. 가장 깊이 매달린 `a + b` 가 먼저 묶이고, 그 결과에 `+ 1` 이 붙는다 —
덧셈이 왼쪽부터 묶인다는 사실이 나무 모양에 들어 있다.

노드의 가로 자리는 그 노드가 끝내 덮는 토큰들의 가운데다. 그래서 한 번 매달린 노드는 끝까지 움직이지 않는다.

나무는 차례를 잊고 모양만 남긴다. 가장 오른쪽 유도로 매달아도 매다는 차례만 다를 뿐 **같은 나무**가 된다.

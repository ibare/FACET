L1 벌점 λ·Σ|w| 을 건 모형에서 갱신 한 번은 두 마디다. 먼저 데이터 걸음이 무게를 벌점 없이 맞춘 자리 a 쪽으로 조금 되돌리고, 이어 L1 끌기가 무게를 0 쪽으로 η·λ 만큼 끈다. 이 끌기는 무게의 크기와 상관이 없다 — 1.10 이든 0.26 이든 한 갱신에 같은 폭 0.12 만큼 끌린다.

{facet:pushToZero}

처음 모습(갱신 0)을 넣어 일곱 걸음이다. 무게 여섯이 a 에서 출발해 갱신마다 노란 띠만큼 가운데 0 의 벽으로 끌려온다. 살아 있는 줄의 띠는 모두 같은 길이다. 폭을 못 버티는 작은 무게는 차례로 벽에 닿는다 — w6 은 갱신 1, w5 는 갱신 2, w4 는 갱신 4 에. 끌기는 0 을 건너 반대 부호로 넘어가지 않고 0 에서 멈추므로, 닿은 무게는 네모가 되어 벽에 붙는다. 다음 갱신에서 데이터가 조금 들어 올려도 L1 이 그만큼 되눌러 정확히 0 에 머문다. 그래서 0 인 무게의 개수는 줄지 않고 0, 1, 2, 2, 3, 3, 3 으로 늘기만 한다.

큰 무게 w1 · w2 · w3 은 끌리고도 0 에 닿지 않는다. 여섯 번째 갱신에서 0.81 · −0.41 · 0.16 에 있고, 아직 가는 자리에 다 닿지는 않았다 — 조각은 거기서 멈춘다. L2 벌점이 무게를 같은 비율로 오그라뜨려 0 에 닿게 하지 않는 것과 달리, L1 은 같은 폭으로 끌어 작은 무게를 정확히 0 으로 만든다. 이것이 L1 이 희소한 모형을 낳는 까닭이다.

전제 — 데이터 손실을 ½·Σ(w − a)² 로 두었다. 특징이 서로 겹치지 않고(직교) 크기가 1 인 선형 회귀로 줄인 모형이라 무게마다 따로 셈할 수 있다. 시작 무게를 벌점 없이 다 맞춘 자리 a 로 둔 것은 고른 초깃값이다 (η = 0.4 · λ = 0.30).

## 한 줄을 더해 옮김도 곱으로

**2×2 행렬은 늘이고 돌리고 비틀 수는 있어도 옮기지는 못한다.** 어떤 2×2 행렬 M 이든 M · (0, 0) = (0, 0) 이라 원점은 늘 원점에 남는다. 좌표에 셋째 칸 1 을 붙이면 3×3 행렬의 셋째 열이 그 1 과 곱해져 x 와 y 에 그대로 더해진다 — 옮김도 곱 하나가 된다.

### 숫자로 보면

옮김은 (3, −1) 하나다. 이것을 셋째 열에 넣어 3×3 행렬을 만든다.

```
1  0   3
0  1  −1
0  0   1
```

점 셋 o (0, 0) · p (1, 2) · q (−2, 1) 에 먼저 셋째 칸 1 을 붙이고, 한 점씩 곱한다. 처음 화면까지 걸음 다섯이다.

- o (0, 0, 1) → (3, −1, 1) — x = 0 + 0 + 3 · 1, y = 0 + 0 + (−1) · 1
- p (1, 2, 1) → (4, 1, 1)
- q (−2, 1, 1) → (1, 0, 1)

행렬의 왼쪽 위 2×2 는 단위 행렬이라 x 와 y 를 그대로 옮겨 놓고, 더해지는 몫은 모두 셋째 열 × 1 = (3, −1) 에서 온다. 그래서 세 점 모두 같은 (3, −1) 만큼 떠나고, 원점 o 도 (3, −1) 로 간다. 셋째 행 (0, 0, 1) 은 붙은 1 을 다시 1 로 남긴다 — 결과를 그대로 평면의 점 (x, y) 로 읽으면 된다.

### 전제

- 좌표계는 x 가 오른쪽, **y 가 위**다. 행렬은 열 벡터에 왼쪽에서 곱한다 (p' = M · p).
- 여기서 셋째 칸은 늘 1 이다. 셋째 칸이 1 이 아닌 좌표를 w 로 나누어 평면의 점으로 되돌리는 이야기는 따로 있다.
- 세 칸으로 보면 이 곱은 3차원에서 w = 1 인 평면을 기울이는(shear) 선형 변환이다. 선형 변환은 원점을 못 옮기지만, 평면 w = 1 위의 점들은 기울임을 따라 통째로 미끄러진다 — 2차원에서 본 옮김이 3차원에서는 선형이 된다.
- 크기 · 회전 행렬도 같은 3×3 의 왼쪽 위 2×2 에 넣을 수 있어서, 옮김과 섞은 변환을 곱 하나로 묶어 둘 수 있다.

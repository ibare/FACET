# 외우기와 일반화

본 문제를 다 맞히는 쪽이 새 문제도 잘 맞히는가?

{facet:memorizeVsGeneralize}

두 답안자가 같은 예 여섯을 받는다. x 가 하나씩 붙은 문제와 그 정답(0 또는 1)이다.

- **외운 쪽**은 여섯을 표로 쥔다. 표에 같은 x 가 있으면 그 답을, 없으면 가장 가까운 x 의 답을 낸다.
  여기서는 이웃을 하나만 보는 가장 단순한 외우기로 두었다.
- **배운 쪽**은 규칙 하나만 쥔다 — "x 가 문턱 t 보다 크면 1". 문턱 후보는 정렬한 x 에서 이웃한 둘의 가운데 다섯이고,
  본 것에서 틀린 수가 가장 적은 t = 4.20 을 고른다 (그때 틀린 수 1).

예 가운데 x = 7.3 의 답 0 은 **잘못 매긴 것**이다. 나머지 예와 새 문제는 모두 "x 가 크면 1" 을 따른다.
데이터는 이 뒤바뀜이 보이도록 고른 장난감 데이터다.

## 무엇을 보는가

걸음은 모두 열둘이다 — 두 쪽이 준비를 마친 처음 화면, 본 문제 여섯, 새 문제 다섯. 한 걸음마다 문제 하나를 두 쪽에 함께 묻는다.
위 수직선에 문제 x 가 내려오면, 외운 쪽은 가장 가까운 예로 호를 그어 그 답을 가져오고, 배운 쪽은 점선 문턱의 어느 쪽인지로 답한다.
아래 두 줄은 경주다. 맞히면 토큰이 한 칸 나아가고, 지금 쪽에서 앞선 답안자가 위 자리에 선다.

- **본 문제**에서 외운 쪽은 6/6 이다. 잘못 매긴 7.3 까지 그대로 외워서 맞힌다. 배운 쪽은 문턱 하나로 7.3 을 1 로 답해 5/6 이다.
  외운 쪽이 한 칸 앞서 나간다.
- **새 문제**로 넘어가면 7.0 과 7.6 에서 외운 쪽의 가장 가까운 예가 잘못 외운 7.3 이다. 외운 쪽은 연달아 틀려 3/5,
  배운 쪽은 따라잡아 앞서며 5/5 다. 세 번째 새 문제에서 두 자리가 뒤바뀐다.

배운 쪽의 5/5 는 이 새 문제 다섯에서의 결과일 뿐, 배운 쪽이 늘 다 맞힌다는 뜻은 아니다.
본 것 점수는 얼마나 잘 외웠는지를, 새 것 점수는 얼마나 일반화했는지를 잰다. 둘이 어긋날 때가 과적합이다.

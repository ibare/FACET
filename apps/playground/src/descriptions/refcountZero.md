## 세던 수가 0 이 되면 그 줄에서 치운다

참조 계수(reference counting)는 객체마다 **몇 개의 이름이 자기를 가리키는지** 수 하나를 붙여 둔다.
이름이 객체를 가리키게 되면 수가 하나 오르고, 가리키던 이름이 손을 놓으면 하나 내린다. 수가 0 이 되면
그 객체에 닿을 길이 없으니 곧바로 치운다. 따로 멈춰 서서 힙을 훑는 단계가 없다 — 0 이 된 **그 줄 바로
뒤에** 일어난다.

{facet:refcountZero}

### 오르내리는 수

첫 줄 `let a = new Node()` 가 객체 `A` 를 만들고 `a` 가 그것을 가리킨다. 수는 1 이다. 이어서
`let b = a` 와 `let c = b` 가 같은 객체를 가리키는 이름을 둘 더 만들어 수는 2, 3 으로 오른다. 객체는
하나이고, 늘어난 것은 가리키는 손이다.

그다음 세 줄은 손을 하나씩 놓는다. `a = null` 로 3 에서 2, `c = null` 로 1, `b = null` 로 0. 걸음은
시작을 포함해 모두 여덟이고, 수의 자취는 1 · 2 · 3 · 2 · 1 · 0 이다.

### 누가 만들었는지가 아니라 몇이 가리키는지

객체를 만든 이름은 `a` 인데 가장 먼저 손을 놓은 것도 `a` 다. 그래도 `A` 는 치워지지 않고 두 걸음을 더
산다 — 그때도 `b` 와 `c` 가 가리키고 있기 때문이다. 참조 계수는 만든 이를 기억하지 않는다. 마지막 손인
`b` 가 놓아 수가 0 이 된 줄 바로 다음 걸음에서 `A` 가 거둬지고, 끝에는 남은 객체가 없다.

### 이 그림의 모형

- `Node` 는 필드 `next` 하나를 가진 작은 객체이고 처음 값은 `null` 이다. 이 프로그램에서는 필드를 쓰지
  않으므로 객체를 가리키는 것은 이름 칸 셋뿐이다.
- 칸 주소 500 · 501 · 502 는 흐름을 보이려고 **예로 정한 값**이다. 실제 주소는 실행 환경이 정한다.
- 수를 셀 때는 새로 가리키는 쪽을 먼저 올리고 놓는 쪽을 나중에 내린다.
- 코드는 어느 한 언어가 아닌 읽히는 표기로 적었다. 파이썬(CPython) · 스위프트 · 오브젝티브-C 가 이
  방식으로 객체를 거둔다. 서로를 가리키는 객체끼리는 수가 0 에 이르지 못하는데, 그것은 순환 참조
  쪽에서 따로 다룬다.

# 변환을 잇는 행렬 곱

변환 두 개를 잇따라 걸면, 그 둘을 행렬 하나로 적을 수 있을까? 그리고 차례를 바꾸면, 되돌리려면, 하나가 평면을
납작하게 누르면 무엇이 달라질까?

{facet:matrixOps}

## 읽는 법

행렬은 행 차례로 적는다. `[a b ; c d]` 는 윗줄이 a b, 아랫줄이 c d 다. 점 p = (x, y) 는 세로 벡터로 보고 행렬을
왼쪽에서 곱한다 — 점이 가는 자리는 A p = (a·x + b·y, c·x + d·y) 다. 행렬의 열은 기저 (1, 0) · (0, 1) 이 가는
자리이고, 행렬 곱하기 벡터는 그 열들을 x · y 만큼 더한 것이다. 그래서 행렬 하나가 평면 위 모든 점을 한꺼번에
옮긴다.

**오른쪽에 쓴 것이 먼저 걸린다.** "먼저 X · 다음 Y" 는 곱 **YX** 이고 점에는 Y (X p) 가 된다. 차례를 바꾼 곱은
**XY** 다.

## 한 판 — 걸음 여섯

1. **처음** — 점 넷 (1, 1) · (2, −1) · (−1, 2) · (1, 2) 가 처음 자리에 선다. 카드 X · Y 에 기호 · 행렬 ·
   이름 · det 이 뜬다.
2. **X 로 뛴다** — 점 넷이 함께 X p 로 뛴다. 캡션은 점들이 선 서로 다른 자리의 수를 센다.
3. **Y 로 뛴다** — 또 한 번 Y (X p) 로. 자리 수와 함께, 처음 자리에 다시 선 점(제자리)을 센다.
4. **곱** — YX 카드가 서고 det Y × det X = det YX 가 수 하나로 셈된다. 점은 움직이지 않는다.
5. **YX 로 한 번에** — 처음 자리의 자국에서 고리가 YX 로 한 번에 뛰어, 두 번 간 점 위에 포개진다.
6. **XY 로 한 번에** — 차례를 바꾼 XY 로 뛴 유령(점선 마름모)이 따로 선다. YX 의 자리와 같은 곳에 선 유령을
   센다.

걸음마다 2.2 초(걸음 1.6 초 + 운동 0.6 초)를 쉬어, 처음부터 끝까지 11.0 초가 걸린다. 끝나면 손잡이를 기다린다.
손잡이 **먼저** · **다음** 을 돌리면 점들이 제 마지막 자리에서 처음 자리로 미끄러져 돌아오고, 같은 점 넷이 새
길로 뛴다.

## 여섯 변환

| 기호 | 이름 | 행렬 | det |
| --- | --- | --- | --- |
| R | 반시계로 직각 | [0 −1 ; 1 0] | 1 |
| R⁻¹ | 시계로 직각 | [0 1 ; −1 0] | 1 |
| H | 옆으로 밀기 | [1 1 ; 0 1] | 1 |
| S | 세로 두 배 | [1 0 ; 0 2] | 2 |
| F | 위아래 뒤집기 | [1 0 ; 0 −1] | −1 |
| P | 가로축으로 납작 | [1 0 ; 0 0] | 0 |

## 36 짝에서 세어 보면

- **두 번 뛴 자리 = YX 로 한 번에 뛴 자리.** 36 짝 모두, 점 넷 모두에서 걸음 5 의 수는 4 / 4 다.
- **차례를 바꿔도 같은 곳** — 36 짝 가운데 14 짝(같은 변환끼리 여섯 짝과 R · R⁻¹ · S · F · S · P · F · P 의
  양쪽 차례)에서 같은 곳 4 / 4, 나머지 22 짝에서는 0 / 4 다. 이 예에는 중간값이 없다.
- **제자리 4 / 4** 는 YX 가 아무것도 하지 않는 행렬 [1 0 ; 0 1] 이 되는 세 짝뿐이다 — R → R⁻¹ · R⁻¹ → R ·
  F → F.
- **제자리 1 / 4** 가 뜨는 두 짝(R⁻¹ → F · F → R)은 되돌림이 아니다. 두 짝의 YX 는 [0 1 ; 1 0], 곧 직선
  y = x 에 대한 뒤집기라서 그 직선 위의 점 (1, 1) 만 그대로 남는다.
- **P 가 끼면** (11 짝) det Y · det X 가운데 하나가 0 이라 det YX = 0 이 되고, 서로 다른 두 점이 한 자리에 포개진다(자리 3). 포갠 자리에는
  `×2` 표지가 붙는다. 어느 점에서 왔는지 모르는 자리가 생기니 되돌리는 행렬이 있을 수 없고, 그래서 이 11 짝 어디서도
  제자리 4 / 4 가 나오지 않는다. P 가 먼저면 첫 뜀에서 이미, P 가 다음이면 둘째 뜀에서 포개진다.

## 전제

- 변환 여섯과 점 넷은 예로 정한 값이다. 36 짝을 모두 보아도 모든 행렬에 대한 증명은 아니다. 일반에 서는 것은
  곱의 결합 법칙 (YX) p = Y (X p) 와 det(YX) = det Y · det X 둘이다 — 화면은 그것을 이 예에서 세어 보일 뿐이다.
- 모든 수가 정수라 "같은 곳" 은 좌표가 정확히 같은지로 가린다. 허용 오차를 두지 않는다.
- 점이 뛰는 호는 출발과 도착을 잇는 그림일 뿐이다. 운동 도중의 자리에는 값이 없다.
- det 은 여기서 수 하나로만 쓴다. 넓이 · 평행사변형으로 그리지 않는다.

## 이어서 볼 조각

- **matrix-product-chain** — 기본 판(H 먼저 · S 다음)이 그 조각의 짝이다. 여기서는 짝이 36 개로 는다.
- **inverse-undoes** — 되돌리는 짝 셋이 제자리 4 / 4 로 선다. 역행렬을 셈하지 않고 손잡이로 찾는다.
- **determinant-zero-collapse** — P 가 낀 짝에서 점이 포개지는 까닭.
- **determinant-area** — det Y × det X = det YX 를 넓이로 읽는 법.
- **matrix-as-transform** · **matrix-columns-are-basis** · **matvec-as-combination** — 행렬이 점을 옮기는 법,
  열이 기저가 간 자리라는 것, 행렬 곱하기 벡터가 열의 가중합이라는 것.
- 선형대수 입문 흐름으로는 벡터 연산 조각들(화살표 · 꼬리 잇기 · 늘이기 · 정규화 · 내적의 그림자 · 외적)이
  이 앞에 선다.

벡터를 더한다는 것은 화살표를 **잇는** 일이다. 원점에 꼬리를 둔 화살표 셋 a = (3, 1) · b = (1, 2) · c = (−2, 1) 가운데 a 는 제자리에서 첫 마디가 되고, b 가 꼬리를 a 의 머리 (3, 1) 로 옮겨 붙는다. 이은 끝은 (4, 3) 으로 옮겨 간다. 이어 c 가 꼬리를 (4, 3) 에 붙이면 이은 끝은 (2, 4) 가 된다.

마지막에 처음 꼬리(원점)에서 마지막 머리까지 화살표 하나를 그으면 그것이 합 a + b + c 다. 그 끝 (2, 4) 는 오른쪽 칸에서 성분끼리 더한 수와 같다 — x 는 3 + 1 + (−2) = 2, y 는 1 + 2 + 1 = 4. 그림으로 잇는 것과 수로 더하는 것이 같은 끝에 닿는다.

c 의 x 성분이 음수라 이은 길은 오른쪽으로 갔다가 왼쪽으로 굽어 돌아온다. 이은 길 길이의 합은 7.63 이고 합 화살표의 길이는 4.47 이다. 합은 어디를 거쳐 왔는지가 아니라 **어디에 닿았는지**만 남긴다.

화살표를 옮기는 까닭은 잇기 위해서다. 화살표는 꼬리를 어디에 두어도 같은 벡터이므로, 앞 머리에 붙여도 b 와 c 는 그대로 b 와 c 다. 잇는 차례를 바꾸어 c → a → b 로 이어도 길의 모양만 달라질 뿐 끝은 같은 (2, 4) 에 닿는다 — 덧셈의 교환 법칙이 그림에서는 이렇게 보인다. 이 조각은 차례 하나만 보인다.

값은 예로 정한 것이다. 걸음은 처음 화면을 넣어 넷이고, 걸음마다 2 초를 머물고 운동은 0.8 초라 전체 재생은 약 8 초다. 같은 덧셈은 물리에서 힘과 변위를 합칠 때, 그래픽에서 위치에 이동량을 더할 때 그대로 쓰인다.

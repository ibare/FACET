## 배운 창은 무엇에 반응하는가

합성곱 신경망의 첫 층은 3×3 같은 작은 창 여럿을 배운다. 학습이 끝난 창을 열어 보면 값이 제멋대로 흩어져 있지
않고, 한쪽이 음수 · 다른 쪽이 양수로 갈린 경계 모양이나 줄무늬 모양을 닮은 경우가 많다. 그렇다면 그 창은
실제로 무엇에 가장 크게 반응할까. 여러 무늬를 하나씩 창에 대 보면 알 수 있다.

### 창 하나, 무늬 다섯

창은 위에 제자리로 서 있다. 무게는 이렇다.

```
−1.0   0.2   1.1
−1.2   0.1   0.9
−0.8  −0.1   1.0
```

아래 받침에 무늬 다섯이 놓여 있다 — 세로 경계(왼쪽 어둡고 오른쪽 밝음), 가로 경계(아래 줄만 밝음), 고른 면(전부
밝음), 대각선, 뒤집힌 세로 경계(왼쪽 밝고 오른쪽 어두움). 밝기는 0(어두움)과 1(밝음) 두 가지다. 화면은 무늬의
밝기와 창의 무게를 같은 회색 사다리로 칠한다 — 음수일수록 어둡고 양수일수록 밝다. 그래서 창 자체도 왼쪽이
어둡고 오른쪽이 밝은 그림으로 보인다.

### 맞대고, 늘어선다

재생은 처음 화면을 넣어 일곱 걸음이다. 처음에는 창만 있고, 걸음 1 부터 5 까지 무늬가 데이터 차례대로 하나씩
받침에서 올라와 창 왼쪽에 맞대어진다. 응답은 같은 자리의 밝기와 무게를 곱한 아홉 개의 합이다 — 편향도 활성
함수도 두지 않아서 음수 응답도 그대로 보인다. 응답은 받침의 그 무늬 자리에 막대로 선다. 위로 서면 양수,
아래로 내려가면 음수다.

| 무늬 | 응답 |
| --- | --- |
| 세로 경계 | 3.0 |
| 가로 경계 | 0.1 |
| 고른 면 | 0.2 |
| 대각선 | 0.4 |
| 뒤집힌 세로 경계 | −3.0 |

마지막 걸음에서 무늬들이 응답 큰 것부터 받침 위를 옮겨 늘어선다 — 세로 경계 · 대각선 · 고른 면 · 가로 경계 ·
뒤집힌 세로 경계. 맨 앞은 창과 밝고 어두운 자리가 같은 무늬이고, 맨 뒤는 그것을 뒤집은 무늬다. 창의 값이 곧
그 창이 찾는 무늬의 모양이라는 뜻이다. 고른 면의 응답이 0 가까이인 것도 같은 까닭이다 — 음수 무게와 양수
무게가 거의 상쇄된다.

### 이 그림이 정한 것

- 창의 무게는 학습으로 얻은 것이 아니라 **예로 정한 값**이다. 실제로 학습된 CNN 의 첫 층 창이 경계 · 줄무늬를
  닮는다는 알려진 경향을 본떠 골랐다. 학습 과정은 그리지 않는다.
- 셈은 딥러닝 틀들이 "합성곱" 이라 부르는 **교차 상관**이다 — 창을 뒤집지 않고 같은 자리끼리 곱한다. 채널은 하나,
  편향과 활성 함수는 없다.
- 응답은 배정도로 끝까지 셈하고 표시만 소수 한 자리로 줄인다.
- 창이 입력 위를 밀려 가며 특징 지도를 채우는 모습은 여기서 다루지 않는다. 여기서는 창이 가만히 있고 무늬가
  창으로 온다.

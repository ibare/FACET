# 같은 낱말, 같은 뜻

검색 증강에서 조각을 찾는 길은 크게 둘이다. **낱말로 찾는 검색**(BM25 같은 것)은 질의의
낱말이 글에 몇 번, 얼마나 드물게 나오는지를 센다. **뜻으로 찾는 검색**은 질의와 글을 각각
벡터로 바꾸고 둘 사이의 코사인을 잰다. 둘은 같은 질의에 서로 다른 문서를 먼저 내민다.

{facet:sameWordVsSameMeaning}

질의는 `cheap flights to paris` 이고 문서는 다섯이다. 처음에는 두 줄 모두 식별자 순으로
서 있어 같은 문서를 잇는 끈이 나란하다. 왼쪽 줄이 BM25 점수대로 다시 서면 질의 낱말을
품은 글이 위로 오른다. `budget airline tickets from london to the french capital` 인 d2 는
질의와 겹치는 낱말이 하나도 없어 0 점이고, 같은 0 점인 d5 와 함께 바닥으로 가라앉는다.
오른쪽 줄이 코사인대로 서면 그 d2 가 맨 위로 떠오른다. 반대로 `cheap` · `paris` 두 낱말이
겹치는 d1(파리의 호텔 이야기)은 왼쪽 2위에서 오른쪽 4위로 내려간다. 두 끈이 엇갈리는 자리가
두 검색이 다르게 찾아오는 자리다.

낱말 쪽은 말을 바꿔 쓴 글(`flights` 대신 `airline tickets`, `paris` 대신 `french capital`)을
놓치고, 뜻 쪽은 낱말이 정확히 맞아야 하는 질의(상품 번호나 고유 이름)에 약하다. 그래서 둘을
함께 쓰는 **혼합 검색**이 흔하다.

## 셈의 규약

- 낱말 쪽 BM25 는 k1 = 1.2, b = 0.75, idf = ln((N − n + 0.5)/(n + 0.5) + 1) 로 셈한다.
  토큰은 소문자로 바꾸고 영숫자 덩이로 가른 뒤 불용어 스물둘을 뺀다. 어간 처리는 하지 않는다
  (`flights` 와 `flight` 는 다른 토큰이다).
- 등수는 점수가 높은 순이고, 점수가 같으면 식별자 순이다. 이 자료에서는 BM25 의 d2 · d5 가
  둘 다 0 점이라 여기서 걸린다.
- 끝 걸음에 굵게 남는 두 끈은 두 줄 사이 등수가 가장 많이 오른 문서와 가장 많이 내린 문서다.
  내린 폭은 d1 과 d3 이 둘 다 두 칸으로 같아, 뜻 쪽에서 더 아래에 선 d1 을 골랐다.

## 이 그림이 줄여 놓은 것

- 뜻 쪽의 벡터는 **예로 정한 값**이다. 임베딩 모형이 낸 값이 아니고, 세 축에도 이름이 없다.
  실제 임베딩은 수백에서 수천 차원이고 모형이 글을 읽어 만든다. 여기서는 "뜻이 가까우면
  벡터가 가깝다" 는 가정만 빌려 왔다.
- 문서가 다섯뿐이라 BM25 의 idf 가 거칠다. 문서가 많아지면 흔한 낱말의 무게가 더 줄어든다.

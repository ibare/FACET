# 한 걸음씩 걷어낸다

확산 모형이 그림을 만들 때는 원본이 없다. 순수 잡음 x₅ 에서 출발해, 걸음마다 두 가지를 한다.

1. **맞힌다** — 지금의 x_t 에 섞인 잡음 ε̂ 을 예측한다. 그 예측이 옳다면 잡음을 뺀 깨끗한 그림은 x̂₀ 다.
2. **내려선다** — 맞힌 잡음을 **전부가 아니라 일부만** 덜어 평균으로 옮기고, 작은 새 잡음(σ_t · z)을 얹어 x_{t−1} 로 내려선다.

## 화면 읽기

- 위의 계단은 x₅ 에서 x₀ 까지다. 걷어낼 때마다 새 그림이 한 계단 아래로 내려앉는다. 네 칸의 짙기가 값이다.
- 가운데 수직선 넷은 칸 하나씩이다. 점이 x_t, 마름모가 x̂₀ 이고, 색 눈금 P · Q 는 배운 자료 두 그림의 자리다.
  걷어내는 걸음에서 점은 먼저 평균 쪽으로 끌려가고(덜어 낸 몫), 이어 새 잡음만큼 튄다. 오른쪽 μ 기둥이 그 평균이다.
- 아래 띠는 예측기가 자료 P · Q 에 준 무게다. 옆의 작은 그림이 x̂₀ 다.

처음 x̂₀ 는 P 와 Q 의 섞임이라 흐리다(무게 P 0.58 · Q 0.42). 걸음이 갈수록 한쪽으로 기울어 0.65 → 0.82 → 1.00 이 되고,
x₀ 는 P [1, 1, −1, −1] 에 닿는다 (거리 P 0.00 · Q 2.83). 무게 1.00 · 0.00 은 둘째 자리에서 자른 표시값이다 — Q 의 무게는 아주 작을 뿐 0 은 아니다.

걸음은 모두 열하나다 (처음 화면을 넣어서). t 다섯 개마다 예측 한 걸음과 걷어냄 한 걸음.

## 이 그림이 정한 것

- **예로 정한 값** — 칸 넷, 걸음 다섯, 배운 자료 둘(P [1, 1, −1, −1] · Q [−1, 1, 1, −1]), 잡음 일정 β = 0.05 · 0.15 · 0.3 · 0.5 · 0.7,
  시작 잡음 x₅ 와 걸음마다 더하는 새 잡음 z 는 미리 뽑아 둔 값이다.
- **예측기** — 학습된 신경망 대신, 배운 자료가 P · Q 둘뿐일 때의 **이상적 예측기**를 쓴다. 무게는
  softmax(−‖x_t − √ᾱ_t · xᵢ‖² / (2(1 − ᾱ_t))) 로, x_t 가 각 자료를 √ᾱ_t 배로 줄인 자리에 얼마나 가까운가에서 나온다.
  그래서 끝이 자료 하나와 똑같아진다. 실제 신경망은 배운 자료를 그대로 되풀이하지 않고 비슷한 새 그림을 낸다.
- **걸음의 식** — DDPM 의 조상 샘플링. ᾱ_t = Π(1 − β_s), 평균 = (x_t − β_t / √(1 − ᾱ_t) · ε̂) / √(1 − β_t),
  새 잡음의 크기는 σ_t² = β_t 로 골랐다. 마지막 걸음(t = 1)에는 새 잡음을 더하지 않는다.

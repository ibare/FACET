# 모든 무게가 같은 비율로 줄어든다

L2 벌점은 무게를 0 으로 만드는가. 이 조각은 무게 둘(w1 · w2)을 가로 · 세로 변으로 삼은 네모 하나로 답한다.
원점 모서리는 붙박혀 있고, 맞은편 모서리가 원점과 시작 자리 a 를 잇는 점선을 따라 원점 쪽으로 미끄러진다.

갱신 한 번마다 L2 몫 η·λ·w 가 **지금 무게에 비례해** 빠진다. 1.60 인 w1 에서는 0.240, 0.40 인 w2 에서는
0.060 — 큰 무게는 크게, 작은 무게는 작게 준다. 이 몫은 읽음표의 수다.

네모에서 깎여 나간 ㄱ 자 띠는 **이번 갱신에 줄어든 양**이다. 한 갱신은 L2 몫을 빼면서 데이터 쪽으로 η·(a − w) 만큼
되끌리기도 해서, 띠와 L2 몫은 갱신 1 에서만 같다(갱신 2 의 w1 은 0.13 줄었고 L2 몫은 0.204). 그래도 두 무게가 같은
비율로 줄어서 w1 쪽(오른쪽) 띠는 두껍고 w2 쪽(위쪽) 띠는 얇으며, 네모는 꼴을 바꾸지 않고 오그라든다. 처음 대비 남은 비율은
두 무게가 걸음마다 같은 수(0.85 → 0.77 → 0.72 → 0.70 → 0.68)이고 두 무게의 비 w1 / w2 는 내내 4.00 이다.

작은 무게도 0 에 닿지 않는다. 갱신 다섯 번 뒤 w2 는 0.27 로 남는다. 몫이 무게에 비례하니 무게가 작아질수록 빠지는 몫도
작아져, 모서리는 원점에 다가가다 말고 느려진다. 재생은 처음 모습을 넣어 걸음 여섯(갱신 0 ~ 5)이며, 갱신 5 에서 멈춘다 —
그 자리가 더 갈 곳 없는 끝은 아니다.

전제: 데이터 손실 ½·Σ(w − a)² 는 특징이 서로 겹치지 않는(직교하고 크기 1 인) 선형 회귀로 줄인 모형이고, 시작 무게를
벌점 없이 맞춘 자리 a = (1.60, 0.40) 로 둔 것은 고른 초깃값이다. η = 0.3 · λ = 0.5 로 두었다.

# 쿼리 · 키 · 값

셀프 어텐션에서 한 토큰이 다른 토큰의 정보를 가져올 때, 무엇으로 묻고 무엇에 맞춰 보며 실제로 가져오는 것은 무엇인가.

{facet:queryKeyValue}

토큰 셋 A · B · C 는 저마다 입력 x 하나를 가진다. 같은 x 가 세 행렬을 지나면 서로 다른 세 벡터로 갈라진다 —
물음 q = x·W_Q, 열쇠 k = x·W_K, 값 v = x·W_V. 여기서 묻는 토큰은 C 하나라 물음은 C 의 것만 셈하고, 열쇠와 값은 셋 모두 셈한다.

C 의 물음 q_C = (-2.00, 3.00) 이 열쇠 셋과 차례로 맞춰진다. 점수는 q_C·k 를 √d_k 로 나눈 것이다 (여기서 d_k 는 2).
나누기 전의 곱은 A -4 · B 6 · C 2, 나눈 점수는 A -2.83 · B 4.24 · C 1.41 이다. softmax 를 지나면 무게는 A 0.00 · B 0.94 · C 0.06 이 되고
가장 잘 맞은 열쇠는 B 의 것이다. A 의 무게는 0.00 으로 보이지만 0 은 아니다 (softmax 는 0 을 내지 않는다).

C 의 자리로 옮겨 오는 것은 무게만큼 섞인 값이다: 0.00·v_A + 0.94·v_B + 0.06·v_C = (2.88, 0.94).
B 의 세 벡터 x_B (0.00, 1.00) · k_B (0.00, 2.00) · v_B (3.00, 1.00) 가운데 이 결과와 가장 가까운 것은 v_B 다 (거리 x_B 2.89 · k_B 3.07 · v_B 0.13).
맞춰 보는 데 쓴 열쇠와 실제로 가져오는 값은 다른 벡터다.

걸음은 처음 화면을 넣어 일곱이다 — 처음 · 물음 · 열쇠 · 값 · 맞춰 보기 · 무게 · 가져오기.

## 전제

- 입력 · 투영 행렬 · 차원 2 는 예로 정한 값이다. 실제 모형의 행렬은 학습으로 정해진 값이고 차원도 훨씬 크다.
- 벡터는 행 벡터이고 행렬을 오른쪽에서 곱한다.
- softmax 는 셈이 넘치지 않도록 가장 큰 점수를 빼고 셈한다. 결과는 같다.
- 어텐션 한 번만 셈한다 — 여러 머리 · 출력 투영(W_O) · 잔차 · 층 정규화는 없다.
- 거리는 두 벡터 사이의 유클리드 거리다. 화면의 수는 소수 둘째 자리로 보이지만 셈은 자르지 않고 한다.

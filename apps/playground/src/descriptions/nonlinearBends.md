층 사이에 활성화 함수를 두지 않고 층을 여럿 쌓으면 무엇이 될까. 층 하나는 `출력 = W·입력 + b` 라서, 입력이 x 하나일 때 어느 단위의 출력도 `a·x + b` 꼴의 곧은 선이다. 그 선들을 다시 무게로 섞고 절편을 더해도 여전히 `a·x + b` 다.

{facet:nonlinearBends}

그림은 층을 띠로 아래에서 위로 쌓는다. 맨 아래 띠는 입력 x 자신이고, 층을 하나 더할 때마다 앞 층의 선들이 새 띠로 올라가며 기울기와 높이를 바꾼다. 층 1 은 1.50·x + 0.50 과 −1.00·x + 1.00, 층 2 는 −0.25·x + 1.25 와 −2.00·x − 0.50, 층 3 은 0.75·x + 2.00 이다 (x 가 −2 에서 2 로 가는 동안 0.50 에서 3.50 까지). 어느 단위의 기울기도 0 이 아니어서 선이 눕지는 않지만, 어느 것도 굽지 않는다.

마지막 걸음에서 세 층의 무게를 곱해 한 층으로 접는다 — 기울기는 W3·W2·W1 = 0.75, 절편은 W3·(W2·b1 + b2) + b3 = 2.00. 이 한 층의 선이 층 3 의 선 위에 그대로 겹친다. 층을 셋 쌓아도 한 층이 할 수 있는 일밖에 못 한다는 뜻이고, 층 사이에 ReLU 같은 굽힘을 넣어야 비로소 쌓는 값어치가 생긴다.

재생은 처음 모습(입력 x 만)을 넣어 다섯 걸음이다 — 입력, 층 1 · 2 · 3 을 하나씩 쌓기, 한 층으로 접기.

전제: 여기 쓴 무게(W1 = [[1.5], [−1]], b1 = (0.5, 1) · W2 = [[0.5, 1], [−1, 0.5]], b2 = (0, −0.5) · W3 = [[1, −0.5]], b3 = (0.5))는 학습한 것이 아니라 **예로 고른 값**이다. 어떤 무게를 골라도 활성화가 없으면 결과는 같다 — 늘 곧은 선 하나로 접힌다.

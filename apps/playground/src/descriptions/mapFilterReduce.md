## map / filter / reduce

목록 `marks = [6, 3, 8, 1, 5, 9]` 가 세 단계를 한 줄로 지난다.

```
let kept = filter(marks, x => x > 4)
let squares = map(kept, x => x * x)
let sum = reduce(squares, 0, (acc, x) => acc + x)
```

세 단계는 각자 **한 가지만** 바꾼다.

- **filter** 는 개수를 바꾼다. 원소가 하나씩 문 앞에 서서, 조건이 참이면 값 그대로 지나 kept 줄 끝에 붙고
  거짓이면 떨어진다. 남은 원소의 차례는 원래 차례 그대로다.
- **map** 은 값을 바꾼다. kept 의 원소가 하나씩 문을 지나며 제곱이 되어 squares 의 **같은 자리**에 선다.
  개수는 그대로다.
- **reduce** 는 모양을 바꾼다. 시작값 0 에서 squares 의 원소를 앞에서부터 하나씩 누적에 접어 넣어 수 하나를 낸다.

넘기는 함수(`x => x > 4` · `x => x * x` · `(acc, x) => acc + x`)는 각 문에 꽂힌 칩이다. 칩은 단계가 셈한 값이
아니라 단계에 건넨 **값으로서의 함수**다.

### 문턱을 돌려 보기

문턱을 4 에서 6 으로 올리면 앞 판에 문을 지나던 6 과 5 가 이번엔 문 앞에서 떨어진다. filter 를 지난 수가 4 에서
2 로 줄고, map 뒤의 수도 똑같이 2 로 준다 — map 은 개수를 바꾸지 않기 때문이다. 답은 206 에서 145 로 줄어든다.
문턱을 내리면 떨어졌던 원소가 되살아 문을 지난다.

| 문턱 | filter 뒤 | map 뒤 | 답 |
| --- | --- | --- | --- |
| 0 | 6, 3, 8, 1, 5, 9 | 36, 9, 64, 1, 25, 81 | 216 |
| 2 | 6, 3, 8, 5, 9 | 36, 9, 64, 25, 81 | 215 |
| 4 | 6, 8, 5, 9 | 36, 64, 25, 81 | 206 |
| 6 | 8, 9 | 64, 81 | 145 |
| 8 | 9 | 81 | 81 |

견줌은 `x > 문턱` 이라 문턱과 **같은** 원소는 떨어진다. 문턱 6 에서 원소 6 이, 문턱 8 에서 원소 8 이 그렇다.
칸 번호는 코드의 색인처럼 0 부터 센다.

### 코드 패널 — 세 단계를 반복으로 편 모습

화면은 함수를 값으로 넘기지만, 코드 패널은 같은 셈을 세 단계가 **속에서** 하는 반복으로 편다. 코드 패널은 여섯
언어가 함께 쓰는 한 벌의 셈에서 옮겨 오는데, 그 셈에는 함수를 값으로 담는 자리가 없다(여섯 언어 모두 함수를 값으로
넘길 수 있지만 그 꼴이 서로 다르다). 그래서 넘기는 함수가 반복 몸에 박혀 있다 — `xs[i] > threshold`
가 filter 의 칩, `kept[i] * kept[i]` 가 map 의 칩, `acc + squares[i]` 가 reduce 의 칩이다. 반복 한 바퀴가 화면의 걸음
하나와 맞는다. 결과를 담을 목록 `kept` · `squares` 는 부르는 쪽이 marks 길이만큼 만들어 건넨다.

실제 언어에는 이 세 단계에 저마다 이름이 있다.

| 언어 | filter | map | reduce |
| --- | --- | --- | --- |
| 자바스크립트 | `.filter` | `.map` | `.reduce` |
| 파이썬 | `filter` · 컴프리헨션 `[x for x in xs if …]` | `map` · 컴프리헨션 | `functools.reduce` (합이면 `sum`) |
| 자바 | 스트림 `filter` | 스트림 `map` | 스트림 `reduce` |
| C# | LINQ `Where` | LINQ `Select` | LINQ `Aggregate` |
| C++ | `std::copy_if` | `std::transform` | `std::accumulate` |

화면의 표기는 목록이 첫 인자다(`filter(marks, f)` · `reduce(list, start, f)`). 실제 언어의 인자 차례나 메서드 꼴과
다를 수 있다 — 자바스크립트는 `marks.filter(f)` 처럼 목록 뒤에 점을 찍고, 파이썬의 `filter(f, marks)` 는 함수가
먼저 오며, `functools.reduce(f, xs, start)` 는 시작값이 맨 뒤에 온다.

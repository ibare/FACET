# 외적 — 둘 다에 수직인 방향

{facet:crossProductPerpendicular}

3차원의 두 벡터 a · b 에 둘 다 수직인 방향은 한 줄 위의 두 쪽이다. 외적 a × b 는 그 가운데 어느 쪽을 가리키고, 정말 둘 다에 수직일까?

## 무엇을 보나

- **걸음 0** — a = (2, 1, 0) 과 b = (1, 2, 2) 가 원점에서 뻗어 판 하나를 벌린다. 둘의 사이각은 53.4° 다. 판 위의 호는 a 에서 b 로 도는 차례를 가리킨다.
- **걸음 1** — c = a × b 를 세 성분 한꺼번에 셈한다. c₁ = a₂b₃ − a₃b₂ = 1×2 − 0×2 = 2, c₂ = a₃b₁ − a₁b₃ = 0×1 − 2×2 = −4, c₃ = a₁b₂ − a₂b₁ = 2×2 − 1×1 = 3. c = (2, −4, 3) 이 판을 뚫고 선다.
- **걸음 2** — a·c = 2×2 + 1×(−4) + 0×3 = 0. a 와 c 의 사이각 90.0°.
- **걸음 3** — b·c = 1×2 + 2×(−4) + 2×3 = 0. b 와 c 의 사이각 90.0°.
- **걸음 4** — 차례를 바꾼 b × a = (−2, 4, −3) = −(a × b). 화살표가 c 의 머리에서 원점을 지나 같은 줄의 반대쪽으로 넘어가고, 호의 화살 머리도 a 쪽으로 옮겨 간다. 이것도 a·(b × a) = 0, b·(b × a) = 0 이다.

처음 화면을 넣어 걸음 다섯, 재생은 10 초 남짓이다 (걸음 사이 2 초 · 운동 0.6 초 넷).

## 어느 쪽인가 — 오른손

둘 다에 수직인 줄은 하나지만 그 위의 방향은 둘이다. 외적은 (a, b, a × b) 가 **오른손**을 이루는 쪽을 고른다. 오른손 손가락을 a 에서 b 로 감아쥐면 엄지가 가리키는 쪽이다. 그림에서 판을 위에서 내려다보면 a 에서 b 로 도는 호가 시계 반대 방향이고, c 는 보는 이 쪽으로 서 있다. 차례를 바꾸면 감는 방향이 뒤집히고, 엄지도 반대쪽을 가리킨다. 그래서 외적은 바꿈 법칙이 성립하지 않는다 — a × b = −(b × a).

이 그림은 **오른손 좌표계**(x → y → z 가 오른손)를 쓴다. 3차원을 평면에 옮길 때 거울상으로 뒤집지 않는 투영을 골랐다. 좌표계를 왼손으로 잡으면 같은 셈이 반대쪽을 가리키는 것처럼 보인다.

## 왜 둘 다에 수직인가

a·(a × b) 를 풀어 쓰면 a₁(a₂b₃ − a₃b₂) + a₂(a₃b₁ − a₁b₃) + a₃(a₁b₂ − a₂b₁) 이고, 여섯 항이 둘씩 지워져 늘 0 이다. b 도 같다. 걸음 2 · 3 의 0 은 이 예의 우연이 아니라 식이 그렇게 짜여 있기 때문이다. 정수 성분이라 셈에 오차가 없이 정확히 0 이 나온다.

## 전제

- a = (2, 1, 0) · b = (1, 2, 2) 는 예로 정한 값이다. 서로 수직이 아닌 둘을 골랐다 — 서로 수직인 둘이면 c 가 축처럼 보여, 판에 수직이라는 것과 좌표축이라는 것이 가려지지 않는다.
- 이렇게 정의된 외적은 **3차원에서만** 이런 모양이다. 2차원에서 z 성분 하나만 남기는 셈(부호 있는 넓이)이나, 더 높은 차원의 쐐기곱은 이 조각의 말이 아니다.
- |a × b| = √29 ≈ 5.39 는 a · b 가 벌린 평행사변형의 넓이와 같다. 넓이 이야기는 행렬식의 몫이라 이 그림은 방향만 본다.

## 이어서

외적은 판에 수직인 방향(법선)이 필요한 곳 어디에나 나온다. 3차원 그래픽의 면 법선과 조명, 물리의 돌림힘(토크)과 각운동량, 자기장 속 전하가 받는 힘이 모두 두 벡터에서 셋째 방향을 얻는 셈이다. 그리고 셋째 방향의 부호는 늘 차례에 달려 있다.

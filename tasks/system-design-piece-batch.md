## 사양에서 호스트가 정한 것

- **"표기 native" 는 코드 글자가 있을 때만.** 사양 에이전트 셋이 키 · 경로 · 공항 부호 · 상태 코드(`503`)를 "표기 native" 로 달았다.
  이 분야 조각은 화면에 코드 글자가 없다 — 사양 줄을 "자료"(번역하지 않는 `initialData`)로 바꾸고 `@notation native` 를 두지 않게 했다.
- **걸음 0 과 첫 사건이 겹치는 조각**(leaky-bucket 의 0 초, arrival-vs-service 의 시각 0)은 사양의 걸음 수를 따랐다 — silent 로 걸음 0 을 갈아 끼운다.
- **미는 창의 음수 아랫끝**(sliding-window-count)은 셈은 그대로, 그림만 시각 0 에서 잘린다 — clamp 가 아니라 그림의 잘림.
- **clocks-drift 의 맞추기 걸음**은 뺄지 물어 왔다 — "맞춰도 빠르기는 그대로라 다시 벌어진다" 한 주장이라 두었다.

## 감사가 잡은 것

이번에는 C6(모르는 것을 조용히 넘김)이 거의 나오지 않았다 — 공통 안내문에 계약 카드의 C6 줄 · 좁히개 · 무대의 대체값 금지를 처음부터 넣었다.
대신 **캡션 · 화면 · 설명 글의 수가 서로 어긋나는** 꼴이 가장 많았다.

| 꼴 | 예 |
| --- | --- |
| 한 화면에 같은 것을 두 수로 | shed-to-survive — 캡션은 그 틱에 나눈 몫 1/9, 힘 막대는 다음 틱 몫 1/12 |
| 고르기 전 값과 배정 뒤 화면 | send-to-idlest — "열린 수" 동그라미는 고르기 직전 값, 줄에 놓인 연결은 배정 뒤 |
| 셈하지 않은 결론 | consumer-offset "두 오프셋은 제자리" · stale-copy 걸음 0 이 첫 사본 값 하나로 모두를 단정 |
| 설명 글의 틀린 견줌 | evict-least-frequent "LRU 였다면 세 번 모두 /home" — 실제 LRU 로 돌리면 밀어냄 둘 |
| 운동 출발값을 `prev` 에서 | spread-in-turn (S-scene) |
| 그 밖 | clocks-drift 의 `as unknown as ViewInstance`(C9) · 식별자 `A` · `B` 를 표시 이름 없이 · jittered-backoff 의 "받히다"(들이받히다로 읽힌다) |

권고(위반 아님)도 만든 에이전트에게 돌렸다 — 간격 괄호가 요청이 들어오기 전에 보임(leaky-bucket), 운동을 이어진 걸음에서만(read-your-write) 등.
감사 넷이 위반 0 을 내고 권고만 남겼다.

## 호스트 쪽 사고

- 사양 에이전트에게 준 조각 사양 파일 하나를 조각 에이전트가 "형제 사양이 함께 들어 있다" 고 보고했다 — 확인해 보니 쪼갠 파일은 제 절만
  담고 있었다. 에이전트가 잘못 읽은 것으로 보고 넘겼다.

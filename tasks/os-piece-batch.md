# 운영체제 조각 쉰넷 — 배치 기록

2026-09-25. 운영체제 서브도메인 여섯의 미구현 조각 전부를 칸 열로 흘려보냈다. 규범은 `piece-batch-protocol.md` · `piece-contract.md`.
같은 세션에서 완제품까지 닫았다(`os-whole-batch.md`). 개념 메타는 완제품과 **한 묶음으로** 썼다 — 조각 개념을 먼저 쓰지 않았다.

사양이 오는 대로 쪼개 칸 10 에 — 하나 끝나면 대기열에서 다음 (io → process-thread → file-system → memory → scheduling → synchronization)

서브도메인이 닫히는 대로 등록 · 관성

## 사양에서 호스트가 정한 것

- 파일 · 디렉터리 · 프로세스 이름은 **번역하지 않는 자료**다(코드의 식별자와 같다). 한 조각이 `label.file` 로 문안에 두었다가 감사에서
  "정본이 둘" 로 걸려 `initialData` 로 옮겼다
- 순위는 **수가 클수록 높다**(교과서의 흔한 관례와 반대) — 설명 글이 밝히고 완제품 priority 가 같은 방향을 따랐다
- 동기화 표기 `lock(m)` · `acquire(s)` · `wait(c, m)` · `signal(c)` · `work()` 를 받아들여 `pseudo-notation.md` 에 올렸다
- 프레임 · 페이지 번호는 하드웨어가 매긴 값이라 0 부터 둔다(계약의 "번호는 1 부터" 는 등수 · 자리에 걸린다) — 완제품에서 TLB 칸은
  자리라 1 부터로 정정했다
- stepMs 를 사양보다 낮춘 둘(belady-anomaly 1300 → 1100 · lock-ordering 800 → 600)을 받아들였다 — 사양이 재생 길이를 운동 없이 셌다

## 감사가 잡은 것

조각 쉰넷 가운데 **마흔하나가 위반 0**. 지적 · 권고는 모두 만든 에이전트가 고쳤다. 되풀이된 꼴:

| 꼴 | 조각 |
| --- | --- |
| 캡션에 셈하지 않은 결론 · 화면과 다른 사실 ("캐시는 그대로다" · "CPU 를 거친 낱말: 0"(상수) · "아직 아무도 오지 않았다" · "가장 오래전에 돈 것"(아무도 안 돎) · "제자리 반영 끝") | switch-costs · transfer-without-cpu · first-come-first-run · virtual-runtime · write-intent-first |
| 설명 글이 화면 · 모형과 어긋남 (메타데이터만 저널 · 한 틱에 둘이 달림 · 밀리는 조각 수) | replay-after-crash · critical-section · shortest-first |
| 번호와 개수를 같은 모양으로 ("빈 자리: {n}") | swap-in-out |
| 조용히 지나침 · 지어냄 (`?? 0` · 캡션 셋째 줄 버림 · 빈 글자) (C6) | lock-excludes · ready-queue-pick · lost-update · time-slice-rotate |
| 재생 20 초 넘김 (헛 단계 셋) · 걸음 0 이 800ms 아래 | aging · lock-ordering |

## 에이전트가 짚은 것

- **stage 의 문안 조회기 이름은 반드시 `t`** — `tx` · `tl` 로 둔 넷이 en-original 테스트에서 원인 없이 "expected 0 to be greater than 0"
  으로 실패했다. 계약 카드는 반대 방향(헬퍼를 `t` 로 두지 말라)만 적고 있었다 → **카드에 넣음**(넷째가 걸린 뒤)
- 새 디렉터리라 `@ffacet/core` 를 못 찾는다 — 프롬프트에 링크 한 줄을 주어 쉰넷 모두 그렇게 했다 → **두 카드에 넣음**
- `check-lib` 글꼴 크기 검사가 `HOP_RISE_PER_PX` · `DIP_PX` · `MAX_REFS` 를 잡았다 → **검사식을 글자 낱말로 좁힘**
- 밝은 테마의 `success` 가 거의 검정 · `itemActive` · `danger` · `categorical(2)` 가 붉은 · 주황 계열로 겹친다 — 조각 다섯이 따로 짚었다.
  토큰 층 결정이라 이 배치에서 고치지 않았다
- rule-guard 정의의 "화면에 상시 전제 각주가 있는가" 줄을 감사 둘이 "있어야 한다" 로 읽었다 → **"있으면 위반" 으로 문구 고침**
- 장면 `reduce` 가 모르는 이벤트에 장면을 그대로 돌려주는 꼴(관행 960 곳)을 감사가 C6 후보로 올렸다 — 규범 조항이 없어 이 배치에서는 올리지 않게 했다.
  위반으로 세려면 `S-scene` 에 조항부터

# 조각 코드 표기 규약 — 어느 언어도 아닌, 읽히는 표기

> 2026-09-25 확정. 결정 넷은 모두 권고안으로 정했다 (아래 "정한 것").

조각 화면에 **프로그램 텍스트**가 뜰 때 쓰는 표기다. 프로그래밍 기초 분야가 첫 대상이고(제어 흐름 여덟이 파이썬
표기로 먼저 나왔다), 변수 · 함수 · 객체 지향 · 함수형 · 메모리 모델 조각 쉰 남짓이 뒤따른다.

## 왜 있나

조각은 **흐름의 모양 하나**를 말하는 자리다 — 되돌아간다, 거슬러 오른다, 한쪽만 간다. 특정 언어의 문법을 쓰면 그 언어를
모르는 학습자는 주장보다 **문법을 먼저 해독**해야 한다. 제어 흐름 여덟의 파이썬 표기에는 파이썬에만 있는 것
(`def` · `elif` · `raise` · `except` · `print` · 줄 끝 콜론 · `RecursionError`)이 섞여 있었다.

그렇다고 새로 지은 표기가 **또 하나 배워야 할 언어**가 되면 허들이 바뀔 뿐이다. 그래서 이 규약의 잣대는 둘이다.

1. **처음 보는 사람이 설명 없이 읽는다.** 키워드는 뜻 그대로의 영어 낱말, 기호는 수학 시간에 본 것.
2. **어느 실제 언어로 가도 옮겨 간다.** 거의 모든 언어가 공유하는 낱말(`if` · `else` · `while` · `for` · `function` · `return`
   · `class` · `new` · `throw` · `try` · `catch`)을 그대로 쓴다. 한 언어에만 있는 낱말은 쓰지 않는다.

**층 나눔** — 조각은 이 표기로 개념을 잡고, 완제품은 코드 패널에서 IR 을 **실제 여섯 언어**로 옮겨 보인다. 조각의 표기를
실제 언어에 맞추려 애쓰지 않는다. 그 다리는 완제품이 놓는다.

## 적용 범위

- **쓴다** — 조각 화면에 프로그램 텍스트가 뜨는 모든 곳. 설명 글 · 개념 메타에서 그 코드를 인용할 때도 같은 표기.
  다만 설명 글 · 개념 메타가 **실제 언어의 사실을 말하는 것**은 막지 않는다 — "파이썬의 기본 재귀 한도는 1000 이다" 처럼 전제를
  밝히거나 실제 언어로 잇는 문장은 오히려 좋다. 규약이 거는 것은 **코드 표기**다
- **쓰지 않는다**
  - 주장이 **특정 언어 · 런타임에 묶인** 조각 — 이벤트 루프(`setTimeout` · `Promise` 는 자바스크립트 그 자체다), 특정 언어의
    동작을 말하는 조각. 그때는 그 언어를 쓰고 사양에 까닭을 적는다.
  - 컴파일러 분야처럼 **문법 자체가 소재**인 조각 — 사양이 장난감 문법을 따로 정의한다.
  - 완제품의 코드 패널 — IR 과 transpiler 의 몫이다.

## 표기

### 줄과 몸

- **몸은 들여쓰기로만 가른다.** 빈칸 넷. 줄 끝 콜론 · 중괄호 · `end` 를 두지 않는다 — 줄이 짧고, 한 줄 = 한 걸음 셈이 흔들리지 않는다.
- 한 줄에 문 하나. 세미콜론 없음.
- **주석을 두지 않는다.** 설명은 캡션과 설명 글의 몫이다 (IR 주석을 영어로 두는 완제품 규약과 다른 자리다 — 조각의 코드는 짧다).

### 값

| 무엇 | 표기 | 비고 |
| --- | --- | --- |
| 정수 · 실수 | `42` · `3.5` · `-3` | |
| 참 · 거짓 | `true` · `false` | 파이썬의 `True` 가 아니다 |
| 글자 | `"bad value"` | 큰따옴표만 |
| 없음 | `null` | `None` · `nil` · `nothing` 이 아니다 |
| 목록 | `[1, 2, 3]` | |
| 목록 읽기 | `list[0]` | **0 부터** (정한 것 ②) |
| 길이 | `length(list)` | `len` · `.size()` 가 아니다 |

### 연산

| 무엇 | 표기 |
| --- | --- |
| 넣기(대입) | `x = 5` |
| 같다 · 다르다 | `==` · `!=` |
| 크기 견줌 | `<` · `<=` · `>` · `>=` |
| 산술 | `+` · `-` · `*` · `/` (나눗셈은 실수) |
| 몫 · 나머지 | `a div b` · `a mod b` — `//` · `%` 는 쓰지 않는다 (처음 보는 사람이 못 읽는다) |
| 논리 | `and` · `or` · `not` — `&&` · `\|\|` · `!` 는 쓰지 않는다 |
| 글자 잇기 | `"a" + "b"` |

### 변수 — 선언이 있다 (정한 것 ①)

- **선언이 있다.** 처음 만들 때 `let x = 5`, 그 뒤로는 `x = 6`. 바뀌지 않는 값은 `const`.
  `let` 으로 만든 이름은 **그 몸 안에서만** 산다 (블록 스코프). 몸 안의 `let x` 는 바깥 `x` 를 **가린다** — 몸 안의 `x = …` 는
  안쪽 `x` 에 넣고 바깥 `x` 는 바뀌지 않으며, 몸을 벗어나면 바깥 `x` 가 다시 보인다. 몸을 다시 밟으면(반복) 안쪽 이름은 새로 선다
  (2026-09-25 loop-termination 이 짚은 빈자리. 섀도잉 조각의 전제다).
  같은 몸 안에서 같은 이름을 두 번 `let` 하지 않는다. **한 줄에 선언 하나** — `let a = 1, b = 2` 로 묶지 않는다.
  갈래 · 반복의 몸 안에서 값을 넣고 몸 밖에서도 쓰는 이름은 몸 **앞에서** 처음 값과 함께 선언한다.
  자바스크립트 · 자바 · C# · C · 러스트 · 스위프트가 모두 선언과 대입을 가른다. "대입이 곧 선언" 은 파이썬 · 루비의 방식이다.
  변수 · 타입 서브도메인의 섀도잉(`shadowing`) · 스코프 종료(`scope-exit`) · 댕글링 참조는 **선언이 없으면 말할 수 없다.**
- 고르지 않은 안 — "대입이 곧 선언"(파이썬처럼 `x = 5` 가 만들고 넣는다). 줄은 가장 짧지만 스코프 조각들이 `let` 을 따로
  들여와야 해 표기가 한 분야 안에서 갈린다.

타입을 말해야 하는 조각(원시 타입 · 축소 변환)만 `let n: int8 = 100` 처럼 타입을 붙인다. 타입 이름은 `int` · `int8` · `int32`
· `float` · `bool` · `string`. 그 밖의 조각은 타입을 적지 않는다.

### 흐름

```
if score >= 90
    grade = "A"
else if score >= 80
    grade = "B"
else
    grade = "F"

while i <= 3
    total = total + i
    i = i + 1

for i from 1 to 3
    show i

for each item in list
    show item
```

- `else if` 는 두 낱말 (`elif` · `elsif` 가 아니다)
- `for i from 1 to 3` 은 **양 끝을 포함한다** — `range(1, 4)` 의 반열린 구간은 처음 보는 사람이 틀리게 읽는다
- `break` · `continue` 는 그대로

### 함수

```
function countdown(n)
    if n > 0
        show n
        countdown(n - 1)

let doubled = map(list, x => x * 2)
```

- 정의는 `function 이름(인자)`. `def` · `fn` · `func` 가 아니다
- 돌려줌은 `return 값`
- **이름 없는 함수** — `x => x * 2`, 인자가 여럿이면 `(a, b) => a + b` (정한 것 ③)
- 출력은 **`show 값`** — `print` 는 "종이에 찍는다" 로 읽혀 처음 보는 사람에게 뜻이 어긋난다. 괄호 없이 쓴다 (함수 부르기와 가른다).
  **식은 하나만** 받는다. 여럿을 보이려면 글자 잇기로 하나를 만들거나(`show "total " + total`) `show` 를 두 줄로 쓴다 — 쉼표로 늘어놓지 않는다
  (2026-09-25 recursion-self-call 이 짚은 빈자리)

### 오류

```
try
    let y = load(-3)
    show y
catch BadValue
    show "bad value"

throw BadValue
```

- `throw` · `try` · `catch` (`raise` · `except` 가 아니다)
- **오류 이름은 뜻이 드러나는 영어 한 덩이** — `BadValue` · `NotFound` · `DivideByZero`. 재귀가 넘치는 것은 `StackOverflow`
  (가장 널리 알려진 이름). 언어 고유의 이름(`ValueError` · `RecursionError` · `NullPointerException`)은 쓰지 않는다

### 객체 (객체 지향 서브도메인용)

```
class Dog extends Animal
    private name
    function speak()
        show this.name + " barks"

let rex = new Dog("Rex")
rex.speak()

interface Speaker
    function speak()

class Robot implements Speaker
```

- `class` · `extends` · `implements` · `interface` · `new` · `this` · `private` · `public` — 자바 · C# · 타입스크립트가 공유하는 낱말
- 만들 때 부르는 것은 `function create(…)` — `__init__` · `constructor` 가 아니다 (정한 것 ④)

### 메모리 (메모리 모델 서브도메인용)

- 주소 얻기 `address(x)`, 따라가기 `valueAt(p)`, 빌리기 `allocate(3)`, 돌려주기 `free(p)`. **`&x` · `*p` 는 쓰지 않는다** —
  C 를 모르면 가장 먼저 막히는 기호다 (정한 것 ④)

### 이름

- 식별자는 **영어 낱말 하나**가 원칙 (`total` · `score` · `count`). 둘이면 camelCase (`maxDepth`)
- 한 글자 이름은 수학처럼 쓰일 때만 (`i` · `n` · `x`)

## 정한 것

| | 자리 | 정한 것 | 까닭 |
| --- | --- | --- | --- |
| ① | 변수 선언 | **안 A** — `let` / `const` | 스코프 조각 일곱이 선언 없이는 말할 수 없다. "대입이 곧 선언" 이 오히려 파이썬 고유 |
| ② | 목록 첫 자리 | **0 부터** | 실제 언어 거의 전부가 0. 화면의 "몇 번째" 는 지금처럼 1 부터 읽는 자리에서 따로 적는다 |
| ③ | 이름 없는 함수 | **`x => x * 2`** | 자바스크립트 · C# 이 같고 자바(`->`)도 가깝다. `lambda` 는 파이썬 고유 |
| ④ | 메모리 · 생성자 | **낱말 함수** (`address` · `valueAt` · `create`) | 기호보다 낱말이 설명 없이 읽힌다 |

## 옮기기 — 제어 흐름 여덟

**콜론을 떼고 낱말만 바꾸면 줄 수가 그대로다** — 걸음 차례 · 대조값이 바뀌지 않는다. 바꾸는 것:

| 파이썬 | 이 표기 |
| --- | --- |
| `def f(n):` | `function f(n)` |
| `if c:` · `elif c:` · `else:` | `if c` · `else if c` · `else` |
| `while c:` · `try:` | `while c` · `try` |
| `print(x)` | `show x` |
| `raise ValueError` · `except ValueError:` | `throw BadValue` · `catch BadValue` |
| `RecursionError` (화면 글자) | `StackOverflow` |
| `True` · `False` · `None` | `true` · `false` · `null` |

**선언이 있으므로 둘이 더 바뀐다.**

- `multiway-branch` — `grade` 가 갈래 안에서 처음 생긴다. 사슬 앞에 `let grade = ""` 한 줄이 늘어 줄 번호가 하나씩 밀렸다
  (걸음 7 → 8).
- `branch-take-one-path` — 주장 "안 간 쪽의 `heater` 는 끝내 생기지 않는다" 가 파이썬의 "대입이 곧 선언" 에 기대고 있다. 선언이
  있으면 `heater` 는 앞에서 `let` 으로 이미 있다. 주장을 **"안 간 쪽의 줄은 한 번도 실행되지 않는다 — `heater` 는 처음 값 그대로다"**
  로 바꿨다. 갈래 안에서 값을 넣고 갈래 밖에서도 보이는 이름 **셋**(`wear` · `fan` · `heater`)을 `if` 앞에서 선언해야 해 줄이
  8 → 11, 걸음 6 → 9 가 됐다 (처음 초안은 한 줄이면 된다고 잘못 적었다 — 만든 에이전트가 짚었다). 그림의 형태는 그대로다.

나머지 여섯은 낱말 교체와 설명 글 · 개념 메타의 "파이썬 표기" 문장 교체로 끝난다.

## 검사

`piece-check` 가 조각의 `initialData` 코드 글자에서 **다른 언어의 흔적**을 잡는다:
`def ` · `elif` · `print(` · `raise ` · `except` · `lambda` · `None` · `True` · `False` · 줄 끝 `:` · `&&` · `||` · `%` · `//`.
적용 범위 밖의 조각(런타임 · 문법 소재)은 사양이 표지를 달아 뺀다.

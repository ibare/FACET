# S-piece-batch. 조각을 여러 개 만들 때

조각 하나를 만드는 규범은 `S-piece` 다. 이 문서는 **여러 개를 한 묶음으로 만들
때만** 더해지는 절차다.

## 왜 있는가

배치로 만들면 관성이 생긴다. 두 번 겪었다.

- 발췌 15종 — 전부 폐기했다. 같은 파이프라인에 작은 입력을 넣었더니 축척·라벨·
  움직임이 부모 그대로였다.
- 조각 6종 한 번에 — 관성 넷을 찾아 재작업했다. `text()` 헬퍼가 8/9 바이트 단위로
  같았고, 좌표 골격이 5/9 같았고, 위치 애니메이션이 0건이었다.

반면 **하나씩 만든 처음 셋은 겪지 않았다.**

원인은 둘이다.

1. **앞 조각의 코드를 열어 놓고 시작한다.** 골격을 복사하는 순간 질문이 아니라
   템플릿이 형태를 정한다.
2. **규범 자체가 템플릿이 된다.** `S-piece` 의 형태 조항(`PIECE_CANVAS_W`,
   reactive, `stepMs`, controls)만 기계적으로 지켜지고 "형태는 질문이 정한다" 는
   무시된다. 같은 관성이 C2 위반까지 아홉 곳에 똑같이 복제된 적이 있다.

격리는 1번만 막는다. 2번은 사양을 어떻게 쓰느냐에 달렸다.

## 절차

1. **묶음을 정한다.** 서브도메인 하나, 최대 10개. 같은 분야를 묶는 편이 검출에
   유리하다 — 비슷한 것끼리 모아 놓아야 복제가 눈에 띈다.
2. **사양을 쓴다.** 아래 서식대로. 형태를 적지 않는 것이 요점이다.
3. **화면에 뜰 값을 호스트가 확정한다.** 해시·크기·좌표·바이트 수를 계산해 사양에
   박아 넣는다.
4. **서브에이전트에 동시에 던진다.** 순차로 돌리면 앞 결과가 뒷 사양에 스민다.
5. **계측한다.** `node scripts/piece-inertia.mjs <stage 파일...>`
6. **사람에게 확인받는다.** 계측을 통과한 것만 올린다.

## 사양 서식

```
개념      머클 트리
묘사      잎의 해시가 부모로 올라간다
동사      올라간다 — 아래에서 위로. 원본은 남고 복제본이 움직인다
데이터    (호스트가 계산한 실측값)
계약      rules/specifics/S-piece.md 전문 + C2 + C9 + C10
금지      다른 조각의 파일을 열지 말 것. 형태는 동사에서 도출할 것
```

## 호스트 MUST

- **사양에 레이아웃·좌표·색을 적지 않는다.** 적는 순간 호스트가 템플릿이 된다.
  캔버스 폭(`PIECE_CANVAS_W`)은 계약이므로 예외다.
- **화면에 뜰 값은 호스트가 계산해 넘긴다.** 서브에이전트는 값을 지어낸다.
  `hashChain` 에서 해시 뒷자리를 지어내고 주석엔 "전부 실측" 이라 적은 전례가 있다.
- **동시에 던진다.** 순차 실행은 호스트를 관성의 새 원천으로 만든다.
- **등록은 호스트가 나중에 일괄로 한다.** 서브에이전트가 카탈로그·index 를 함께
  건드리면 동시 실행에서 충돌한다.
- **계측을 통과하지 못하면 사람에게 올리기 전에 되돌린다.** 격리는 예방이고
  계측은 검출이라 둘 다 필요하다.

## 서브에이전트 MUST NOT

- **다른 조각의 파일을 열지 않는다.** `facets/**/(*-stage|projector|algorithm).ts`
  를 읽지 않는다. 필요한 계약은 사양과 규칙 문서에 다 있다.
- **화면에 뜰 값을 지어내지 않는다.** 사양에 없으면 호스트에 되묻는다.
- **등록 파일을 건드리지 않는다.** `apps/playground/src/catalog.json`,
  facet index, 카탈로그 codegen 산출물.

## 계측

`scripts/piece-inertia.mjs` 가 넷을 잰다.

| 항목 | 임계 | 근거 |
| --- | --- | --- |
| 최고 코드 유사도 | ≤ 0.50 | 완결형 0.43 |
| 평균 코드 유사도 | ≤ 0.35 | 완결형 0.29 |
| 최고 좌표 겹침 | ≤ 0.60 | 완결형 0.39 |
| 그림 어휘 | ≥ 5종 | 완결형 6종 |
| 운동이 있는 조각 | ≥ 70% | 완결형 4/5 |

근거는 **서로 복제하지 않고 만들어진 완결형 stage 다섯**이다. 조각과 같은
길이(326줄)로 잘라 재서 얻었다 — 짧은 파일일수록 보일러플레이트 비중이 커져
유사도가 높게 나오므로 길이를 맞추지 않으면 비교가 되지 않는다.

**임계는 현재 상태가 아니라 목표선이다.** 조각 아홉(2026-09-07)은 평균 0.49 ·
최고 0.69 · 운동 6/9 로 세 항목이 이 선을 넘는다. 운동은 재작업으로 1/4 에서
6/9 로 올랐지만 **코드 유사도는 0.49 에서 0.49 로 꿈쩍하지 않았다** — 그때의
수정이 골격에는 닿지 않았다는 뜻이고, 계측기가 아니었으면 몰랐을 사실이다.

## 다른 규칙과의 관계

`S-piece` 의 MUST 는 그대로 적용된다. 이 문서는 그 위에 절차만 더한다.
계측은 규칙 위반을 잡지 않는다 — 그것은 rule-guard 의 일이고, 배치 구현 뒤에는
둘 다 돌린다.

# S-scene. 장면(Scene) 방식

## 적용 범위

- `facets/*/*/src/scene.ts`
- `scene:` 를 선언한 `facets/*/*/src/facet.ts` 와 그 stage
- `packages/core/src/runtime/scene.ts`

## 왜 있나

projector 방식은 이벤트를 stage 의 **명령**으로 옮긴다. 상태가 DOM 안에만 있고 명령에
역이 없어 (`revealInputs()` 의 반대가 없다) 임의의 걸음으로 갈 수 없다. 조각 181 을
전수로 재어 되짚기가 온전한 것이 14 뿐이었다.

장면 방식은 이벤트를 **상태**로 옮기고 화면을 그 상태에서 만든다. 어느 걸음의 화면이든
셈으로 얻으므로 되짚기가 앞으로 가기와 같은 연산이 된다.

옮기는 절차와 실측은 `tasks/scene-migration-protocol.md`.

## MUST

- **`initial` 은 넘겨받은 자료를 참조로 담지 않는다.** 러너가 주는 것은 mechanism 과
  view 가 함께 쓰는 한 객체이고 algorithm 이 제자리에서 고친다 (`values[i] = …`).
  참조를 쥐면 되짚을 때 **이미 다 굴러간 자료**로 바탕을 그린다. 값을 복사하거나,
  빈 장면을 돌려주고 `init` 이벤트가 채우게 한다.

- **`reduce` 는 앞 장면을 제자리에서 고치지 않는다.** 되짚기는 지나온 장면들을 그대로
  다시 쓰므로 고치면 과거가 함께 바뀐다. 새 객체를 돌려준다.

- **`reduce` 는 순수해야 한다.** DOM 을 만지지 않고, 타이머를 걸지 않고, 무작위를
  쓰지 않는다. 같은 장면과 같은 이벤트는 언제나 같은 결과여야 한다.

- **`render` 는 늘 그 장면의 화면 **전체**를 세운다.** 앞 장면과 견주어 달라진 것만
  고치지 않는다. 어느 걸음에서 오든 결과가 같아야 하고, 그래야 되돌릴 명령을 따로 둘
  필요가 없다. `prev` 는 **무엇을 흐르게 할지 고르는 데만** 쓴다.

- **`opts.animate` 가 거짓이면 타이머도 프레임도 걸지 않는다.** 되짚기가 그 길로
  오므로, 여기서 무언가를 미뤄 두면 되짚은 뒤 화면이 저 혼자 바뀐다 — 되짚은 직후가
  아니라 1 초쯤 뒤에 무너지므로 눈으로도 늦게야 잡힌다.

- **`render` 가 돌려주는 Promise 는 그 장면이 다 선 뒤에 풀린다.** 이것이 바깥이
  걸음의 끝을 아는 유일한 통로다.

- **facet 은 `projector` 와 `scene` 중 하나만 선언한다.** 둘 다 있거나 둘 다 없으면
  러너가 한국어 메시지로 throw 한다.

## MUST NOT

- **장면에 좌표를 담지 않는다.** 어디에 무엇을 놓을지는 질문이 정하는 형태의 일부이고
  캔버스 비율이 바뀌면 뜻이 달라진다 (S-piece). 값·깊이·순서 같은 **구조**를 담고
  자리는 `render` 가 셈한다.

- **장면에 문안을 담지 않는다.** 무엇을 말할지와 그 인자만 담는다.

  ```ts
  caption: { kind: 'pick'; a: number; b: number } | null
  ```

  문자는 `render` 가 `params.t` 로 만든다. 같은 장면을 다른 locale 로 그릴 수 있어야
  하고, 저작자 오버라이드는 그 통로로만 온다 (C10).

- **장면에 DOM 노드나 그 참조를 담지 않는다.** 장면은 화면을 모른다.

- **`isInstant` 와 `onScrubStart` 를 지연 발화를 막는 빗장으로 삼지 않는다.**
  **러너는 장면 조각에서 그 둘을 부르지 않는다** — `timeline.ts` 의 `rewindTo` 는
  `renderStep` 이 있으면 장면을 꺼내 그리고 `onInstant` 앞에서 돌아간다. 달아 두는
  것이 해롭지는 않으나, 그것을 믿고 다른 빗장을 두지 않으면 되짚은 뒤 화면이 저 혼자
  바뀐다. 조각 셋이 그것을 "유일한 장치" 라고 주석에 적어 두었는데 사실이 아니었다.

  실효 있는 것은 둘이다 — **`opts.animate` 검사**와 **세대 빗장**(`render` 첫머리에서
  `gen += 1`, 걸음 함수가 `await` 뒤마다 자기 세대를 확인하고 아니면 화면에 손대지
  않는다). 걸음이 만지는 요소를 정적 그리기가 **매번 새로 만들면** 세대 빗장이 없어도
  되고 (살아남은 옛 운동이 쥔 것은 이미 떨어져 나간 노드다), 바탕이 바뀔 때만 짓고
  속성만 덮어쓰는 요소를 만지면 **필요하다**.

## PREFER

- **머무는 것과 지나가는 것을 가른다.** 반짝였다 돌아오는 강조는 장면에 담되 `render`
  가 `animate` 일 때만 반짝인다. 남는 강조는 정적 그리기에도 넣는다 — 빠뜨리면 되짚었을
  때 사라진다.

- **화면에 한 번에 하나만 보이면 목록을 두지 않는다.** 지금 것 하나와 이미 끝난 것들의
  목록이면 대개 충분하다.

- **걸음 함수를 버리지 않는다.** `animate` 인자를 받게 고쳐 두 쓰임을 겸하게 한다.

  ```ts
  if (!withAnim) { draw(1); return Promise.resolve(); }
  return animate(420, draw);
  ```

- **`render` 의 첫 줄은 `rewind()`.** 늘 비우고 시작하면 되돌릴 것이 없다.

## Exception

- 장면이 커서 걸음마다 쥐기 부담스러운 조각은 앞 장면과 구조를 나눠 쓸 수 있다.
  다만 그 공유 부분은 **누구도 고치지 않는다** — 고치면 과거가 바뀐다.
